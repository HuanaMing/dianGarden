# 任務208：精簡跨裝置存檔狀態並在登入錯誤時顯示登入入口

## 來源
由原任務205總規劃拆分；需待任務207完成後依序執行。

## 工作內容
- 跨裝置存檔區平常僅保留必要的目前同步／登入狀態訊息，移除冗餘常駐說明與不必要操作。
- 登入失敗、登入失效或需要重新登入時，顯示可用的Google登入選項。
- 登入成功後依任務204規則隱藏登入入口。
- 保留訪客花園提示及返回自己的花園入口。
- 不改動Google credential驗證安全邊界、雲端API、衝突處理與存檔核心邏輯。

## 驗收條件
- 正常登入／同步時只顯示必要狀態。
- 登入錯誤／失效時登入入口可見且可操作；登入成功後隱藏。
- 訪客花園與返回自有花園功能正常。
- 不宣稱完成真實Google帳號端到端測試，除非實際執行。
