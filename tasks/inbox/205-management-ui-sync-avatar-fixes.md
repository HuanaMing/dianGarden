# 任務205：管理介面、頭像自動選擇與同步狀態整理

## 需求背景
任務202～204完成後，使用者提出五項介面修正。此任務以現有原生 HTML／CSS／JavaScript 架構為基礎，優先釐清無人機佇列消失的原因，並統一管理介面的尺寸與同步資訊呈現。不改動遊戲經濟、存檔格式或登入驗證機制。

## 工作項目

### 1. 修正無人機管理頁面的工作佇列消失
- 檢查無人機管理面板開啟、全畫面樣式、HUD 收合狀態及佇列更新邏輯，找出佇列不顯示的實際原因。
- 修正後應能看到無人機狀態、工作佇列項目與既有操作控制。
- 保留目前派工、工作取消、自動模式及無人機管理行為，不以隱藏佇列或重寫派工邏輯作為修正。

### 2. 自動頭像仍顯示所有花種並標示目前自動選擇
- 無論頭像來源選擇「自動（種植最多的花）」或「手動選擇」，都顯示完整 11 種花卉選項。
- 自動模式下仍禁止手動指定花種；花種清單只供查看。
- 清楚標示系統目前自動選中的花卉，並讓標示隨各花種種植數量變化而更新。
- 保留手動模式、既有頭像顯示與存檔行為；平手時沿用目前程式既有的選擇規則。

### 3. 統一三個管理介面的尺寸
- 將農地管理、無人機管理、設定面板的可視尺寸調整為與「自訂頭像」對話框相同的整體視覺尺寸與邊界。
- 桌面及手機皆需適配可用視窗；內容過長時在面板內捲動，不得被畫面裁切。
- 保留三個管理面板互斥開啟、原有關閉方式、設定分頁與 HUD 收合行為。
- 以現有自訂頭像對話框的實際寬度、內距與視窗適配方式作為基準，不另引入新框架。

### 4. 精簡設定中的跨裝置存檔區
- 跨裝置存檔區一般狀態只保留目前同步／登入狀態訊息，不再常駐顯示多餘的說明文字或同步操作選項。
- 當登入失敗、登入失效或需要重新登入時，顯示可用的登入選項；登入成功後依既有規則隱藏登入入口。
- 訪客花園的提示及「回到自己的花園」入口仍須正常顯示。
- 不更動雲端 API、Google credential 驗證、衝突處理、雲端上傳／下載核心邏輯及本機存檔安全性。

### 5. 移動自動儲存提示
- 將「進度會自動儲存」及本機儲存警告訊息，移入「設定 → 同步 → 跨裝置存檔」區域。
- 移除原位置的重複顯示；儲存空間不可用或存檔失敗時，警告仍需清楚可見。
- 保留原本自動儲存觸發時機與存檔行為，不改變遊戲進度儲存策略。

## 驗收條件
- 無人機管理面板開啟時，工作佇列容器與待處理／執行中的工作可正常顯示；無工作時仍顯示清楚的待命或空佇列狀態。
- 自動及手動頭像模式都可看到 11 種花卉；自動模式明確標示目前自動選中的花卉，且不可手動更改選擇。
- 農地管理、無人機管理、設定面板與自訂頭像對話框的尺寸基準一致，桌面及手機內容皆可完整操作。
- 跨裝置存檔區平時只顯示必要的目前狀態；登入錯誤／失效時可使用登入入口，登入成功後仍依任務204規則隱藏。
- 「進度會自動儲存」只在跨裝置存檔區顯示；本機存檔警告狀態仍正確。
- 設定分頁切換、訪客花園、登出、雲端同步及既有存檔回歸行為不受影響。
- 更新 Playwright 瀏覽器回歸測試，涵蓋佇列可見性、頭像自動選擇標示、面板尺寸、登入狀態顯示與自動儲存提示位置。
- 執行可用的 JavaScript 語法檢查及 GitHub Actions 瀏覽器驗收；如未使用真實 Google 帳號，須明確註記未做真實帳號端到端驗證。

## 預計涉及檔案
- `src/index.html`：同步區結構及存檔狀態提示位置。
- `src/styles.css`：管理面板尺寸、內容捲動、頭像花種狀態標示及響應式樣式。
- `src/game.js`：頭像選項顯示／自動選中標示與工作佇列呈現（以檢查結果決定必要修改範圍）。
- `src/cloud-save.js`：登入錯誤時的登入入口顯示及同步狀態文案（僅在確認需要時修改）。
- `tests/browser-smoke.mjs`：新增／調整回歸驗收。
- 任務完成後同步必要的狀態、架構文件及工作歷史。

## 執行原則
- 先重現並定位佇列消失的原因，再做最小範圍修正。
- 先檢查現有面板與自訂頭像對話框的實際樣式，不直接假設採全畫面或固定像素尺寸。
- 不改動存檔格式、雲端服務端行為或登入驗證安全邊界。
- 本文件目前為待開始規劃；開始實作前依專案規範確認最新程式與測試狀態。
