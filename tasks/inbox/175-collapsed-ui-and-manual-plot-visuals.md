# 任務 175：收合頂部控制列與農地視覺整合

> 狀態：待執行（2026-10-23）

## 目標
統一收合介面時的頂部控制列、三個主要控制按鈕的彈出面板、農地管理版面，以及手動農地的 3D 外觀，讓介面更像同一組自然延伸的控制元件，並讓手動農地能一眼辨識但不破壞場景協調感。

## 需求
1. 介面收合時，左上角留下的三個按鈕保留白色容器。容器為圓角矩形，並與畫面上緣平滑連接，不呈現像獨立懸浮按鈕的斷裂感。
2. 農地管理面板移到右上角顯示。
3. 收合介面時，農地管理按鈕必須一起隱藏；展開介面後恢復顯示。
4. 農地管理、無人機、設定三個按鈕開啟的面板，都要與觸發按鈕平滑銜接，視覺上像按鈕本身向外延伸。避免面板與按鈕之間出現明顯空隙或不一致的圓角。
5. 農地管理內的農地項目採每排五塊排列。手動／自動農地購買按鈕的容器寬度應精準對齊第五塊農地項目的右緣，不多出一大段空白。
6. 手動農地在 3D 建模上要與自動農地有明顯但克制的視覺差異；差異應能在一般遊戲視角下辨識，不可突兀，也不可降低農地與整體空島場景的協調性。

## 範圍
- 主要修改 src/styles.css、src/index.html、src/game.js、src/sky-world.js；依實際模型資料流調整其他必要檔案。
- 不引入外部 UI 或 3D 套件，不改變存檔格式與遊戲規則。
- 保留手機版可操作性，五欄版面在較窄螢幕上應採合適的縮放或斷點調整，不可造成水平溢出。

## 驗收條件
- 收合後，指定的三個左上角控制按鈕仍位於白色圓角容器中，容器上緣與畫面上緣視覺連續；農地管理按鈕不殘留。
- 農地管理面板位於右上角，並且在收合／展開切換時正確隱藏與顯示。
- 農地管理、無人機、設定面板均與各自觸發按鈕自然銜接；開啟和關閉狀態沒有突兀的縫隙、錯位或遮擋。
- 農地清單桌面版每排五塊；購買按鈕區右緣與第五塊農地項目的右緣對齊。
- 手動農地與自動農地可從 3D 外觀辨識；顏色、邊緣、紋理或幾何差異保持低調，且不影響選取、拖曳、種植、成熟、收成與場景效能。
- 手機版介面不水平溢出，主要面板仍可讀、可操作。
- 不破壞無人機、設定、介面收合、農地購買、選取及本機存檔。

## 執行順序
1. 檢查目前頂部控制列的 DOM 結構、收合狀態 class 與各面板定位方式。
2. 先調整控制列白色容器與收合／展開的顯示規則。
3. 將農地管理面板移至右上角，調整三個面板與觸發按鈕的銜接方式。
4. 調整農地管理清單為桌面五欄，並讓購買區寬度與清單對齊；補足手機斷點。
5. 追蹤農地模式資料進入 WebGL 地塊模型的路徑，設計並實作低調、易辨識的手動農地外觀差異。
6. 檢查 CSS 覆寫、事件行為、窄螢幕版面及 3D 模型更新流程。
7. 執行適用的靜態／瀏覽器驗收，記錄結果與尚未驗證的項目。

## 注意事項
- 任務 174 已由使用者確認驗收完成。
- 本任務是介面與模型辨識度調整，不應順便重構無關模組。
- 手動農地的視覺差異需根據目前模型實際結構決定，不預先假定使用特定顏色或幾何造型。
