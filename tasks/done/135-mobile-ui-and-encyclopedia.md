# 任務 135：手機介面精簡與花卉圖鑑版面修正

## 狀態
完成程式修改；等待手機與桌面瀏覽器視覺驗收。

## 需求
1. 手機直式隱藏場景操作提示及底部農地快捷列，桌面版保留。
2. 在花園資訊欄加入無人機面板按鈕；預設收合，展開後閒置 5 秒自動收合，互動時重設倒數。
3. 花卉圖鑑手機版模型視窗維持 1:1 正方形。
4. 自訂花卉變種編輯區與模型視窗使用一致寬度規則。

## 修改範圍
- `src/index.html`：新增無人機面板切換按鈕。
- `src/game.js`：面板開關、5 秒自動收合與互動重設倒數。
- `src/styles.css`：手機直式隱藏區塊、無人機面板顯示狀態、圖鑑模型正方形及變種編輯區對齊。
- `docs/architecture.md`：記錄互動與響應式版面行為。

## 驗收條件
- 手機直式隱藏操作提示與農地快捷列，桌面版仍顯示。
- 無人機面板可由資訊欄按鈕開啟／手動收合，5 秒無互動後自動收合。
- 無人機面板內的觸控、點擊、鍵盤、輸入及焦點互動會重設倒數。
- 手機圖鑑模型外框為正方形，WebGL 畫布填滿外框。
- 變種編輯區左右寬度與模型視窗一致。

## 執行結果
- 已更新 HTML、JavaScript、CSS 及架構文件。
- 已透過 GitHub 重新讀取程式碼，確認新按鈕、倒數邏輯及響應式 CSS 規則存在。
- 尚未執行實際手機瀏覽器視覺／觸控測試；需在部署完成後人工驗收。
- 未更動存檔格式、遊戲規則或花卉變種資料格式。
