# 任務 009：加入無人機播種與擴建動畫

## 目標

製作可愛的小型立方體無人機，為播種與空中土地擴建加入動畫。

## 前置任務

- 任務 008：以 3D 場景作為遊戲操作介面。

## 背景

目前播種和購買土地會立即更新，沒有空島農場的角色演出或動作回饋。

## 限制

- 使用原生 WebGL 與 JavaScript，不加入外部模型或動畫套件。
- 無人機以立方體機身和上方旋轉螺旋槳構成。
- 不修改工作區以外的檔案。

## 驗收標準

- [x] 無人機由立方體機身和上方螺旋槳組成，外觀清楚可辨。
- [x] 播種時無人機會飛到指定土地、短暫停留並完成播種演出。
- [x] 擴建時無人機會飛到新位置，土地隨演出出現並拼接至農場。
- [x] 動畫期間同一操作只會扣款及更新一次；取消操作不啟動動畫。
- [x] 動畫結束後，金幣、農地與花卉狀態正確同步到介面及存檔。
- [x] WebGL 不可用或動畫不可播放時，遊戲操作仍會正常完成。

## 狀態

已完成；未執行瀏覽器手動驗收。
