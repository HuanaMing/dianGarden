# 任務 015：將無人機改為單旋翼大地色模型

## 目標

優化現有無人機外觀，改成單一螺旋槳並以大地色系為主。

## 前置任務

- 任務 011：介面和主要操作位置定稿。

## 限制

- 使用原生 WebGL 幾何，不加入外部模型或動畫套件。
- 保留目前無人機機身輪廓及播種、擴建任務入口。
- 單一螺旋槳需可辨識旋轉，模型在預設鏡頭中清楚可見。

## 驗收標準

- [x] 無人機只有一組螺旋槳及旋轉葉片，不殘留原多旋翼組件。
- [x] 機身與配件採土棕、陶土、苔綠等大地色系，與天空及土地有足夠對比。
- [x] 模型朝向、螺旋槳位置與飛行動畫一致，無明顯穿模。
- [x] WebGL 不可用時不影響農場玩法。
