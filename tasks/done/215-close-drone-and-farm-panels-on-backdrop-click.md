# 任務215：無人機與農地管理點擊空白處關閉

## 來源
使用者希望無人機管理與農地管理介面，和設定介面一樣，可以點擊面板外的空白處關閉。

## 工作範圍
- 檢查設定介面現有的 backdrop／外部點擊關閉行為，沿用相同的事件處理模式。
- 無人機管理面板與農地管理面板開啟時，點擊面板外的空白區即可關閉。
- 點擊面板內部、按鈕、清單或輸入控制時，不得誤觸發關閉。
- 同步更新相關按鈕的 `aria-expanded` 或既有可存取狀態，避免視覺狀態與語意狀態不一致。
- 不改變面板內既有操作與其他視窗的關閉規則。

## 預計檢查檔案
- `src/index.html`
- `src/styles.css`
- `src/management-panels.css`
- 無人機管理、農地管理與設定介面的事件處理程式
- `tests/browser-smoke.mjs`

## 驗收條件
- 無人機管理面板開啟後，點擊面板外空白處可關閉。
- 農地管理面板開啟後，點擊面板外空白處可關閉。
- 點擊面板內容與操作控制不會意外關閉面板。
- 關閉後相關按鈕的展開狀態正確。
- 桌面與手機版均通過適當回歸檢查；無法執行的驗收需明確記錄。

## 執行結果
- 已在 `src/game.js` 新增外部點擊處理：點擊無人機或農地管理面板外部時關閉面板，並透過既有的 `setDronePanelOpen(false)`／`setFarmPanelOpen(false)` 同步 `aria-expanded`。
- 面板內部操作不會觸發關閉；開啟的原生 `dialog` 也會被排除，避免點擊農地操作對話框時誤關農地管理面板。
- 已更新 `tests/browser-smoke.mjs`，涵蓋桌面與手機版的面板內部點擊、外部空白點擊、重新開啟與 `aria-expanded` 狀態。
- GitHub Actions 瀏覽器驗收 run [#509](https://github.com/HuanaMing/dianGarden/actions/runs/40160090064) 通過（commit `149c7521ae6460582eb551440de3203239502b04`）。
