# 任務248：星星與日月可見度連動

## 需求
- 星星以八角星形狀繪製，沿用提供的 `addStar(P, C, dir, size, color)` 幾何設計。
- 星星可見度 = 月亮可見度 × 閃爍係數。
- 每顆星有不同閃爍週期，介於 3～5 秒；係數在 0→100%→0 之間平滑循環。
- 星星位置與大小保持穩定，不可每幀隨機跳動。
- 保留日月原有軌道、月相及日間可見度曲線。

## 驗收條件
- 星星為八角閃光形狀，固定分布於天空球上。
- 每顆星獨立閃爍，單次週期為 3～5 秒，明暗連續平滑。
- 星星可見度乘上月亮可見度；月亮不可見時，星星亦不可見。
- 更新瀏覽器回歸測試，確認星星函式、數量、週期範圍與可見度公式。

## 執行紀錄
- 已加入 84 顆固定分布星星，使用可重現的方向、大小、顏色與相位。
- 每顆星以獨立的 3000～5000 毫秒週期，透過餘弦曲線產生 0→100%→0 閃爍。
- 星星透明度採用 `moonOpacity * twinkle`。
