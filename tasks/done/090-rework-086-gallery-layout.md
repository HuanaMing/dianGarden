# 任務 090：重作任務 086 圖鑑版面

## 目標

讓花卉圖鑑在一般瀏覽器視窗內完整顯示；桌面版左側展示 3D 模型、右側提供可獨立捲動的花種卡片。

## 驗收條件

- 頁面不需縮放即可看到模型、返回入口、花種清單與花色變種控制。
- 桌面版模型位於左側，模型展示高度約為視窗高度的 60%；花種資訊卡整合在右側固定容器，容器可上下捲動。
- 保留單一模型切換、選取狀態、花色自訂及變種保存功能。
- 窄螢幕使用適合觸控的版面；捲動花卡時不會移動整個頁面或模型場景。

## 執行結果

已將模型、選取狀態及花色編輯器整理在左側預覽欄；桌面版模型區維持正方形，寬度上限依視窗高度設為 60vh。花種卡片與說明整合至右側容器，容器內獨立垂直捲動。窄視窗改為上方預覽、下方卡片清單，頁面本身不捲動。保留原有模型切換和變種控制的 DOM 識別碼。

未執行測試或瀏覽器操作（依專案指引）。
