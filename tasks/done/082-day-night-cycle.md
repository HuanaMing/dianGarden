# 任務 082：新增日夜循環

## 目標

為花園加入遊戲內日夜循環，並以場景亮度、天空及介面狀態清楚呈現目前時段。

## 驗收條件

- 場景有平順且可辨識的白天、黃昏／清晨及夜晚視覺變化，並顯示目前時段。
- 時段依遊戲內時鐘推進，重新載入後不會無故跳回循環起點。
- 農地、作物和 UI 在不同亮度下仍清晰可辨；循環不改變作物生長規則。
- 提供給任務 083 可直接查詢的「白天」狀態；夜晚時不符合晴朗白天補電條件。
- 不依賴系統所在地時間或外部 API，除非後續需求明確指定。

## 相依與注意

- 採用專案內持續推進的時間來源，將日夜階段及視覺轉換集中管理。
- 此循環與陰雨天氣可共同運作；天氣雲雨效果不得讓夜晚被誤判為白天。

## 執行結果（2026-10-21）

完成：使用可存檔的遊戲內時鐘新增 16 分鐘日夜循環（清晨 1、白天 9、黃昏 1、夜晚 5 分鐘）。狀態列及收合摘要顯示時段，場景背景和亮度平順轉換，夜間顯示月星；日夜不影響生長，並提供完整白天狀態給補電判斷。
