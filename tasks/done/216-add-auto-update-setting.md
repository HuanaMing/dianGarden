# 任務216：設定新增自動更新開關

## 來源
使用者希望在設定介面的「立即更新」旁新增「自動更新」開關。

## 工作範圍
- 在設定介面「立即更新」控制旁新增清楚可辨識的「自動更新」開關。
- 開關必須真正控制自動檢查／更新行為，而非只有視覺效果。
- 將使用者選擇持久保存，重新載入後仍維持設定；沿用專案既有的設定儲存方式。
- 關閉自動更新時，仍允許使用者手動按「立即更新」。
- 更新檢查或版本資訊載入失敗時，不得阻擋遊戲啟動或主要遊戲操作。
- 保留既有版本格式與 GitHub Pages 版本產生流程，不手動回寫部署產生的版本檔。

## 不在範圍內
- 不改動遊戲核心流程或引入新的更新服務。
- 不變更正式部署流程或版本編碼格式。

## 預計檢查檔案
- `src/index.html`
- `src/styles.css`
- `src/management-panels.css`
- `src/version-check.js` 或目前實際負責版本檢查的模組
- 相關設定持久化程式
- `tests/browser-smoke.mjs`

## 驗收條件
- 設定介面中，「自動更新」開關位於「立即更新」旁，版面在桌面與手機均清楚。
- 切換開關後，自動檢查行為依設定啟用／停用。
- 關閉自動更新後，手動「立即更新」仍能執行。
- 重新載入頁面後，設定仍被保留。
- 版本檢查失敗時遊戲仍可啟動與遊玩。
- 相關測試通過，或明確記錄無法驗證的部分。

## 執行結果
- 在設定頁「立即更新」旁新增「自動更新」開關，並調整並排樣式。
- `src/version-check.js` 使用 `diangarden-auto-update-v1` 保存偏好，預設啟用；偵測到版本差異時自動取得最新頁面並完整重新載入。
- 關閉自動更新後保留手動更新；自動更新失敗會提供手動更新提示；版本檢查失敗不會阻擋遊戲啟動。
- Playwright 驗收 run [#515](https://github.com/HuanaMing/dianGarden/actions/runs/40160706280) 通過，包含偏好保存、自動重新載入、手動更新及版本檢查失敗保護。
