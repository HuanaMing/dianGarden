# 任務 104：細化菊花模型

## 目標

細化遊戲中的菊花 3D 模型，提升花型辨識度並維持低多邊形風格與自訂顏色支援。

## 驗收條件

- 修改限於菊花與必要共用幾何輔助，不改變其他花種外觀。
- 成熟模型呈現該花種代表性的花型、花瓣／小花層次及必要葉片特徵。
- 執行結果記錄實際幾何改動及有使用時的形態參考來源。

## 執行結果

菊花花頭改為兩圈共 43 枚細長放射舌狀花，中心新增 32 顆螺旋排列的金色盤花小花，呈現複合花頭層次；花瓣維持自訂花色。形態參考：[Smith College Botanic Garden](https://www.smith.edu/garden/pastexhibits/alummumexhibit/mumalumsforms.html) 對菊花中心盤花與外圈舌狀花的說明。

未執行測試或瀏覽器操作（依專案指引）。
