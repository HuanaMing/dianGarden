# 任務 110：參考網路圖片重作玫瑰模型

## 目標

參考重瓣花園玫瑰的花型照片，重作成熟玫瑰花頭幾何，維持低多邊形風格、自訂花色及既有萼片。

## 驗收條件

- 玫瑰花頭由可辨識的重疊花瓣層構成，外瓣較寬，花心向內收攏。
- 花瓣有淺杯形與邊緣起伏，不再呈現八面體圓珠排列。
- 變更只影響玫瑰成熟模型，並保留自訂顏色與綠色萼片。
- 記錄參考來源及實際幾何改動。

## 執行結果

玫瑰花冠由三圈八面體改為四層交錯花瓣扇片；外層花瓣最寬，內層逐步縮小、升高並收攏。每片以三角面描出瓣面稜線、杯形起伏與略不規則的瓣緣，色階仍從基礎花色或玩家自訂花色生成。五片綠色萼片保留。

形態參考：[David Austin Roses：Bloom Shapes Explained](https://eu.davidaustinroses.com/pages/bloom-shapes-explained) 與 [Sophy’s Rose 品種頁](https://www.davidaustinroses.com/products/sophy-s-rose)，採用重疊同心花瓣、外瓣較大、中心花瓣較小的玫瑰花型特徵。
