# 任務 019：新增安全的農場自動模式

## 目標

新增可啟用與停止的自動模式，讓無人機依序自動播種可負擔的作物，並在成熟後收成／出售。

## 前置任務

- 任務 018：先完成單架無人機任務佇列。
- 任務 013：土地拼接操作已有明確的手動控制。

## 限制

- 自動模式只可播種與收成／出售，不得擴建土地或移動、拼接土地。
- 使用目前種子費用與成熟／收成資料，不可產生負金幣或重複出售。
- 停用自動模式後不再排入新工作；已開始的工作安全完成後停止。
- 金幣不足或無可收成作物時進入待機，不可無限嘗試或建立重複任務。

## 驗收標準

- [ ] 玩家可明確啟用及停用自動模式，介面清楚顯示目前狀態。
- [ ] 自動模式會使用空地種植可負擔作物，並在成熟後收成／出售。
- [ ] 自動模式不會購買土地，也不會變更任何土地座標或拼接方式。
- [ ] 每項自動操作透過單機佇列執行一次，收支與存檔正確。
- [ ] 停用、金幣不足、無空地或沒有成熟作物時能正確待機。
- [ ] WebGL 降級時仍可啟停自動模式並完成其允許的遊戲操作。
