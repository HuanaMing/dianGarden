# 任務 018：以單一無人機序列執行農場任務

## 目標

遊戲中只使用一架無人機，並以任務佇列依序執行播種、收成及擴建等工作；前一個工作結束並返回停靠站後才能開始下一個。

## 前置任務

- 任務 017：無人機可完成任務後回到停靠站。

## 限制

- 不建立第二架無人機或平行執行動畫。
- 操作鎖定與佇列狀態需清楚顯示，防止重複付款或重複提交遊戲狀態。
- 項目取消、失敗及 WebGL 降級時都需確保佇列能繼續或安全停止。

## 驗收標準

- [ ] 同一時刻最多一個無人機任務正在執行。
- [ ] 任務依提交順序執行；下一項只在無人機完成並返回停靠站後啟動。
- [ ] 等待中的任務可見，玩家可取消尚未開始的任務。
- [ ] 每項任務只會扣款及變更作物／土地一次；餘額不足的任務不會執行。
- [ ] WebGL 不可用時仍以序列方式處理操作，無無限等待狀態。
