# 任務 029：依背景知識新增六種花卉

## 執行結果

依背景文件加入鬱金香、康乃馨、菊花、繡球花、薰衣草及牡丹。各作物均有圖示、花名、來源脈絡的花語靈感、種子成本、遊戲成熟時間、收成價格及各自的低多邊形成熟花型。種植選單與自動花種勾選清單自動涵蓋新目錄項。作物目錄升為版本 3，既有作物索引 0–3 不變，新增花卉使用 4–9；版本 2 舊存檔可載入。
