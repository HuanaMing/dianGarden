# 任務 057：為每台無人機配置專屬停靠坪台

## 目標
購買新無人機時，為其建立獨立停靠坪台，並在存檔中保存每台無人機及停靠位置；既有存檔需平順遷移。

## 結果
- 新增 `game.drones` 存檔資料，為每台無人機保存獨立坪台座標及部署狀態；舊版 `droneCount` 存檔載入時會配置坪台並保留原主坪台、機數及農地。
- 購買無人機時會配置新的空閒位置，場景繪出獨立坪台與待命無人機。
- 土地拖動會避開所有坪台，移動主坪台會同步第一台無人機的座標。
- 驗收：全部任務完成後，Edge 無頭瀏覽器成功顯示 3D 場景與坪台 HUD；互動 DevTools 測試連線失敗，未能點擊購買流程。

已完成。
