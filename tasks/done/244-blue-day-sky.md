# 任務244：晴朗白天天空更藍並縮小下方灰白漸層

## 需求
晴朗白天的天空應更藍、更清透，降低畫面下方灰白色漸層的視覺面積，避免整體像陰天。

## 範圍
- 調整晴天天空頂部、中段與底部色票，增加藍色成分並保留柔和過渡。
- 將漸層中段色標由畫面高度 64% 移至 78%，縮小下方色票佔比。
- 不改動夜晚及雨天天空色票。

## 驗收
- 晴天頂部與中段呈現明顯但不刺眼的藍色。
- 底部仍自然淡化，不出現突兀色帶。
- Playwright 規格與 JavaScript 語法檢查通過。
