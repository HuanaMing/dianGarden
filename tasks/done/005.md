# 任務 005：建立作物成長與收成差異

## 目標

讓四種花卉有各自的種子成本、成熟時間及收成金額。

## 限制

- 使用原生 HTML、CSS、JavaScript，不加入外部套件。
- 每種花卉的平衡數值集中定義。
- 不修改工作區以外的檔案。

## 驗收標準

- [x] 每種花卉有不同的種植成本、成熟時間與收成金額。
- [x] 種植、成熟判斷、倒數、進度及收成都使用該花卉的數值。
- [x] 選擇花種時可看到成本與生長時間；成熟時顯示收成金額。
- [x] 金幣不足的花種無法選擇，收成金額符合花種設定。
- [x] 舊存檔花種索引仍可載入、生長及收成。
