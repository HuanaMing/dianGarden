# 任務 073 重作：修正返航完成處的 returnStart 作用域

## 目標

修正無人機完成回呼中的 `returnStart is not defined`，確保省略返航後沒有接上新工作時仍可補播返航。

## 驗收條件

- 完成處使用有效的返航起始時間，不引用 `updateDroneFrame()` 區域外的區域變數。
- 有下一項工作時可接續派工；沒有下一項工作且原航段省略返航時，會沿返航動畫回坪台。
- 完成回呼只執行一次。

## 結果

- 完成：每架無人機的候選動畫結果一併帶出該影格計算的 `returnStart`；完成回呼若需接續返航，改用 `candidate.returnStart` 重設動畫計時，不再引用 map 回呼作用域外的變數。
- 驗收：檢視候選值產生及完成處讀取位置，確認完成回呼仍只執行一次；依工作區規則未執行瀏覽器互動測試。
