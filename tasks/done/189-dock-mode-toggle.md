# 任務189：修正無人機停靠平台短按切換升降模式

> 狀態：已完成並由使用者確認驗收（2026-10-24）

## 問題
無人機停靠平台長按進入拖移模式後，再短按平台無法正常切換至升降模式。

## 修正與執行紀錄
- 修正 `src/sky-world.js` 的停靠平台指標手勢判斷。
- 記錄按下時平台是否已處於拖移模式，避免把拖移模式中的短按誤判為再次進入拖移模式。
- 短按放開時只有原本不在 move 模式才強制進入 move；原本已在 move 模式則由既有模式切換分支切換至 height。
- 保留長按進入拖移模式、實際拖曳移動平台，以及升降拖曳行為。
- 使用者確認本任務已完成驗收；原任務檔中記錄的待驗收狀態已更新。

## 驗收條件
- 待命平台長按後放開，進入拖移模式。
- 在拖移模式下短按同一平台，可切換至升降模式。
- 在拖移模式下拖曳平台，仍可移動平台。
- 從升降模式短按可切回拖移模式；升降拖曳行為不受影響。
