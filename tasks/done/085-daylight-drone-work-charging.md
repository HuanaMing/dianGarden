# 任務 085：晴朗白天無人機工作時同步充電

## 目標

晴朗白天無人機出勤時同時消耗及補充電量，兩種變化都依經過時間計算。

## 驗收條件

- 工作中仍按既有耗電率扣電；只有完整白天且沒有下雨時，同一時間也按補電率加電。
- 其他時段或陰雨時，工作中只扣電；閒置補電條件維持原規則。
- 電量維持 0–100，工作預留門檻使用實際淨消耗估值，不因多機或佇列改變。

## 執行結果

- 完成：工作中依時間差先扣耗電，再於晴朗白天補入日照電量；雨天、夜晚不補電，隱藏頁面且動畫暫停時耗電與補電都暫停。
- 完成：派工保留值仍以全額耗電估算，作為不計入可能日照收益的安全上限。
- 檢視：時間區間取樣、工作／閒置分支、雨夜充電條件、電量上限與派工預留；未執行測試或瀏覽器操作（依專案指引）。
