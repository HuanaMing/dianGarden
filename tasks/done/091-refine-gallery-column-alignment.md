# 任務 091：重作任務 086 圖鑑欄位對齊

## 目標

調整模型、變種編輯器及花種資訊卡的水平位置與寬度，落實使用者指定的邊界對齊及 30px 欄間距。

## 驗收條件

- 桌面版模型與變種名稱輸入區左緣對齊「返回花園」按鈕左緣。
- 變種名稱編輯器整體寬度與模型顯示區相同。
- 資訊卡容器與模型顯示區相隔約 30px，並使用其餘可用寬度。
- 保留既有窄螢幕上下排列及清單捲動行為。

## 執行結果

桌面版左欄和正方形模型均以 `min(60vh, 可用寬度)` 定寬並靠左，與圖鑑內容起始邊界（返回按鈕左緣）對齊。變種編輯器使用相同寬度。資訊卡欄改為佔用其餘空間，與左側固定留 30px。窄螢幕仍上下排列，模型與編輯器同寬且置中。

未執行測試或瀏覽器操作（依專案指引）。
