# 任務195：讓農田地塊跟隨坡面變形

## 需求
讓農田地塊也能像草地一樣，依相鄰地塊高度差變形，而不是只有草地頂面形成斜坡。

## 修改
- 草地與農地都使用共用坡面幾何。
- 共用角點改由正交連通且高度差不超過 0.5 的地塊群組計算一致平均高度，讓草地、農地交界兩側都能跟隨同一坡面。
- 農地種植土壤床的頂面、側面與土壤紋理都依坡面高度變形。
- 保留原有連接限制，不採用對角線連接。
