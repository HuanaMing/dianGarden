# 任務 008：以 3D 場景作為遊戲操作介面

## 目標

讓玩家透過中央 3D 場景選取土地並開啟對應的操作彈出視窗，整合種植、查看生長、收成與擴建流程。

## 背景

目前農地卡片與 3D 場景分開呈現，遊戲操作尚未集中在空中島嶼場景。

## 限制

- 使用原生 HTML、CSS、JavaScript 與 WebGL，不加入外部套件。
- 保留 WebGL 不可用時可使用的操作方式。
- 不修改工作區以外的檔案。

## 驗收標準

- [x] 點擊 3D 土地會彈出該土地的操作介面，並顯示編號及花卉狀態。
- [x] 空地可從彈出介面選花種；生長中的花卉顯示進度與剩餘時間；成熟花卉可從彈出介面收成。
- [x] 擴建土地的入口位於中央 3D 區域，點擊後以彈出介面顯示費用並可確認擴建。
- [x] 取消或關閉彈出介面不會扣款、種植或擴建。
- [x] 支援滑鼠、觸控及鍵盤操作彈出介面，且不影響 3D 相機拖曳。
- [x] WebGL 不可用時仍能完成種植、查看、收成與擴建。
