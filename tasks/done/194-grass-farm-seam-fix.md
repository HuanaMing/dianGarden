# 任務194：修正草地與農地交界

## 問題
任務193修正草地彼此的共用接縫後，草地角點計算只收集純草地，導致草地與平坦農地相鄰時，草地角點沒有貼齊農地頂面。

## 修改
- 共用角點收集所有接觸該世界座標頂點的地塊，不再排除農地。
- 只沿正交相鄰且高度差不超過 0.5 的連通地塊計算，仍不使用對角線。
- 若連通群組含農地，角點以農地平坦頂面高度為錨點；純草地群組仍使用一致的平均高度。
- 新增草地與農地高度差 0.5 時，雙方角點都必須貼齊農地頂面的回歸測試。
