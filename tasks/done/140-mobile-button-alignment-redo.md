# 任務 140（重做）：修正手機版按鈕對齊

## 需求
1. 修正手機版 2D 模式按鈕與「收合介面」按鈕上緣未對齊的問題。
2. 花卉圖鑑按鈕跟隨 2D 模式按鈕往上排列，彼此不得重疊。
3. 手機直向與橫向皆需使用一致的定位基準；不影響桌面版既有位置。

## 原因
`src/styles.css` 存在多組手機媒體查詢，最後一組 `@media(max-width:700px)` 將 `.camera-mode` 與 `.encyclopedia-link` 的 top 值覆蓋為 117px、162px，造成先前的調整沒有生效。

## 修改
- 將最後生效的手機規則修正為 `.camera-mode { top: 72px }`，與 `.hud-toggle { top: 72px }` 對齊。
- 將 `.encyclopedia-link` 設為 `top: 117px`，排列在 2D 模式按鈕下方。
- 桌面版定位維持原樣。

## 驗收條件
- [ ] 手機直向：2D 模式與收合介面按鈕上緣一致。
- [ ] 手機直向：花卉圖鑑位於 2D 模式下方，無重疊。
- [ ] 手機橫向：兩個按鈕仍對齊且無重疊。
- [ ] 桌面版按鈕位置不受影響。

## 結果
已修正 CSS 最後覆蓋規則並提交至 main。等待手機直向、橫向及桌面瀏覽器實際驗收。
