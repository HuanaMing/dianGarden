# 任務 061：將無人機移動改為固定速度

## 目標
無人機各段飛行的速度依移動距離保持一致，航程長短決定所需時間；保留先升高、再水平移動、最後下降的避障順序。

## 完成內容
- 新增固定速度 `DRONE_SPEED = 1.0` 世界單位／秒。
- 垂直爬升、水平航程與垂直下降分段計算距離，再由距離除以速度推算各段時間。
- 所有航段以線性插值移動，移除原先固定飛行時長和緩動造成的變速。
- 播種、收成、澆水、擴建、返航及連續工作共用同一移動速度；作業停留時間仍依任務類型設定。
- 保留碰撞時暫停與避讓邏輯。

## 驗收
Edge 無頭瀏覽器成功載入場景，畫面顯示自動派工下的三台無人機與三塊農地。飛行時間由各航段距離及固定速度推算，遠近不同的坪台與作物不再共用固定飛行秒數。
