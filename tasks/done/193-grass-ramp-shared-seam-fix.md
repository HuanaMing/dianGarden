# 任務193：修正草地斜坡 0.25 單位接縫縫隙

## 問題
相鄰草地斜坡仍出現約 0.25 世界單位的縫隙。上一版雖然讓單塊草地的頂面與側面共用角點，但每塊地獨立推導角點高度，未保證相鄰地塊在同一世界座標頂點得到相同高度。

## 修改
- 相鄰純草地的共用邊緣高度改為兩塊地中心高度的中點，避免 A 地使用 B 的高度、B 地又反向使用 A 的高度。
- 新增以世界座標定位的共用角點高度計算：只考慮接觸該頂點的草地地塊，並沿正交相鄰、相鄰高度差不超過 0.5 的地塊計算連通群組平均高度。
- 草地頂面與四周側面使用同一組共用角點，維持原本不使用對角線連接的規則。
- 更新 Playwright 測試，驗證 81 種高度排列、相鄰高度差 0.5 時的 0.25 中點接縫，以及兩塊相鄰草地從各自方向計算時得到相同角點高度。

## 驗收
- GitHub Actions Playwright 瀏覽器自動驗收通過：run 40063889854。
- 執行了相鄰草地接縫及角點高度回歸測試。
- 尚未人工檢視所有坡地排列的實際畫面截圖；自動測試通過不代表已完成逐像素視覺驗收。
