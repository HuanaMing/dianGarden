# 任務 105：細化薰衣草模型

## 目標

細化遊戲中的薰衣草 3D 模型，提升花型辨識度並維持低多邊形風格與自訂顏色支援。

## 驗收條件

- 修改限於薰衣草與必要共用幾何輔助，不改變其他花種外觀。
- 成熟模型呈現該花種代表性的花型、花瓣／小花層次及必要葉片特徵。
- 執行結果記錄實際幾何改動及有使用時的形態參考來源。

## 執行結果

薰衣草穗改為 7 層輪生簇，每層 4–5 朵小花；每朵以雙唇花冠的兩瓣層次和綠色小苞片呈現，花穗向上收尖並沿用自訂花色。形態參考：[NC State Extension](https://newcropsorganics.ces.ncsu.edu/herb/lavender-history-taxonomy-and-production/) 對薰衣草花穗由多層輪生小花組成的描述。
