# 任務 072：長按拖曳時顯示地塊移動方向

## 問題

地塊長按進入拖曳狀態後，缺少可移動方向的視覺提示。

## 目標

拖曳地塊時，在地塊位置顯示沿場景 X 軸與 Z 軸（畫面地面兩個方向）的箭頭，清楚表示可移動方向。

## 驗收條件

- 只有地塊長按並實際進入拖曳狀態時才顯示兩個方向箭頭。
- 箭頭在旋轉相機下仍對應場景兩個地面軸，且不與土地模型或游標預覽混淆。
- 放開、取消或失去拖曳時箭頭立即消失；選取、短按開窗及坪台拖曳不受影響。
- 手機尺寸及 WebGL 不可用時不造成操作阻礙。

## 相依與注意

- 接續任務 071；箭頭應以拖曳預覽位置為中心，並由既有拖曳狀態控制顯示生命週期。

## 結果

- 完成：拖曳預覽期間在地塊上方加入 X、Z 軸雙向箭頭；箭頭隨預覽更新，拖曳結束或取消後隨預覽清除。
- 驗收：已檢視顯示條件及 pointerup／pointercancel 清理路徑；未在瀏覽器實際操作拖曳，因此未目視確認箭頭顯示。
