# 任務 072 重作：長按到時立即顯示箭頭

## 目標

地塊按住超過 500ms 時立即顯示移動箭頭，不必先移動滑鼠。

## 驗收條件

- 指標按在已選取地塊上且持續按住，超過 500ms 即顯示箭頭。
- 未選取地塊也可按住超過 500ms 後直接進入拖曳提示狀態。
- 尚未移動指標時箭頭仍可見，且以原地塊為中心。
- 指標移動時箭頭跟隨拖曳預覽；放開或取消時清除。

## 結果

- 完成：長按計時改由任何命中的地塊啟動；計時滿 500ms 即選取地塊、建立原位拖曳預覽並重繪軸向箭頭，不需要先移動指標。
- 驗收：檢視 pointerdown、計時器及場景重繪順序；依工作區規則未執行瀏覽器互動測試。
