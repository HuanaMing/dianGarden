# 任務 087：陰雨開始時立即改變土壤顏色

## 目標

讓降雨開始即顯示濕潤土壤色；降雨期間不提前播放澆水水滴動畫，雨停後再顯示濕潤動畫。

## 驗收條件

- `isRaining` 轉為 true 時立即更新每塊農地的土壤色。
- 降雨時段只顯示雨景及濕土色；水滴澆灌動畫在降雨結束後才開始。
- 雨停後的短暫濕潤狀態與一般澆水的土壤色及粒子動畫一致。

## 執行結果

- 完成：明確分開雨天土壤色與澆水後粒子狀態；陰雨開始或結束的環境邊緣會即時重建土地幾何，陰雨期間土壤直接使用濕土色。
- 完成：雨天雨滴效果維持在降雨時段；作物澆水水滴仍只由 `waterUntil` 觸發，供雨停後濕潤效果使用。
- 調整：濕潤粒子在降雨期間暫停顯示，避免與環境雨滴動畫重疊；雨停後再恢復。
- 檢視：天氣邊緣偵測、WebGL 土壤緩衝區重建條件、雨滴與澆水粒子各自條件；未執行測試或瀏覽器操作（依專案指引）。
