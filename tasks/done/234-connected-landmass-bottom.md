# 任務234：連接地塊形成整體底座

## 需求
自動地塊、手動地塊與草地連接時視為整體，以連通群組最低位置作為底面。地塊正下方若已有另一塊地塊，該地塊不生成側面延伸；沒有地塊直接位於下方的地塊，側面才延伸至整體底部。

## 修改
- `src/sky-world.js`：新增連接群組最低底面與直接下方地塊判定。僅當地塊正下方沒有其他地塊時，才生成延伸側面及底部。
- `tests/browser-smoke.mjs`：保留群組底面、孤立地塊及下層地塊判定測試，新增靜態回歸檢查，確保下方有地塊時不會生成側面延伸。

- 連接的自動地塊、手動地塊與草地以整體最低位置形成底座。
