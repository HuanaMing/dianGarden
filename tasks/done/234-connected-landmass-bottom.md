# 任務234：連接地塊形成整體底座

## 需求
自動地塊、手動地塊與草地連接時視為整體，以連通群組最低位置作為底面。同一垂直柱中只要下方任何距離處存在地塊（包含草地或農地），上層地塊不向群組底部延伸，但保留原本 0.5 單位厚度的側面；最底層地塊仍延伸至連通群組底部。

## 修改
- `src/sky-world.js`：新增連接群組最低底面與直接下方地塊判定。以相同 X/Z 座標檢查整條垂直柱；只要任何較低位置存在地塊（包含草地或農地），上層地塊僅保留原本 0.5 單位厚度的側面，不延伸到底部；
- `tests/browser-smoke.mjs`：保留群組底面、孤立地塊及下層地塊判定測試，新增靜態回歸檢查，確保下方有地塊時不會生成側面延伸。
