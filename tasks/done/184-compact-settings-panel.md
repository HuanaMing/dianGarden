# 任務 184：精簡設定面板

## 需求
將遊戲設定面板內的介面盡量壓縮、簡化，減少卡片留白、按鈕高度、文字間距及自訂頭像選擇器的佔用空間；保留所有既有功能與易讀性。

## 範圍
- 只調整設定面板及其子項目的 CSS。
- 自訂頭像仍須完整顯示 11 種花卉，手動／自動模式切換不變。
- 版本資訊、立即更新、2D 模式、重置進度、省電模式、操作說明及存檔狀態均保留。
- 設定面板在窄螢幕與低高度視窗仍可捲動，不遮住無法操作的內容。

## 驗收條件
- 設定面板寬度、內距、卡片間距及控制項高度明顯縮小。
- 頭像花種縮圖以更緊湊的格狀排列，11 種花仍可選取。
- 不移除、不改變任何設定功能。
- 執行可用的瀏覽器 smoke test，檢查設定面板、版本控制與頭像切換回歸。

## 執行結果
- 已縮小設定面板至桌面約 232px、手機約 224px，並依視窗高度限制面板高度及保留捲動。
- 減少版本卡片、自訂頭像卡片、按鈕、操作說明及存檔狀態的內距與高度。
- 頭像選擇器改為 6 欄，11 種花卉全部保留，縮圖由 32px 縮至 22px。
- GitHub Actions 瀏覽器驗收成功：https://github.com/HuanaMing/dianGarden/actions/runs/39955495271
- GitHub Pages 部署成功：https://github.com/HuanaMing/dianGarden/actions/runs/39955488568
- 沒有修改遊戲規則或存檔格式。


## 重做補充：頭像選擇僅顯示像素圖（2026-10-23）

- 依追加需求移除 11 種花卉頭像按鈕下方的花名文字，並隱藏「指定花種」標籤；每個選項保留像素圖及無障礙名稱，點選與手動／自動模式行為不變。
- 頭像按鈕高度由 40px 降至 27px，圖像維持 22×22px，選擇器因此更緊湊。
