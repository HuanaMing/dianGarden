# 任務 007：強化本機存檔容錯

## 目標

讓瀏覽器無法使用本機儲存空間或存檔內容不完整時，遊戲仍能啟動與遊玩，並清楚說明存檔狀態。

## 限制

- 使用瀏覽器原生 API，不加入外部套件或伺服器。
- 不靜默覆寫可讀取但不完整或不支援的既有進度。
- 不修改工作區以外的檔案。

## 驗收標準

- [x] 讀取或寫入儲存空間失敗時，遊戲可在目前頁面繼續遊玩。
- [x] 載入時驗證金幣、農地清單、作物索引、種植時間及存檔版本。
- [x] 持續存檔不可用時，頁首提示重新整理可能遺失本次進度。
- [x] 有效的既有存檔維持自動儲存並可在重新開啟後載入。
- [x] 不提供清除或覆寫既有存檔的一鍵操作。

## 狀態

已完成（尚未進行瀏覽器手動驗收）。

## 執行紀錄

- 驗證金幣、農地陣列、作物索引、種植時間及花卉目錄版本；舊目錄索引仍受支援。
- 捕捉 `localStorage` 讀取、解析及寫入錯誤；錯誤時不覆寫既有資料，遊戲改以記憶體狀態繼續。
- 新增頁首存檔狀態提示，明確告知重新整理可能遺失本次進度。
- 未執行瀏覽器手動驗收。
