# 任務 141：花園名稱即時儲存與頂部資訊卡精簡

## 需求
1. 修正手機版花園名稱編輯時，後方文字遮擋儲存按鈕的問題；改為名稱有效變更時自動儲存。
2. 從最上方花園資訊卡移除農地數量資訊。
3. 縮小金幣數字字體，並保留桌面與手機版的響應式排版。

## 修改
- `src/index.html`：移除花園名稱編輯表單的儲存及取消按鈕，保留名稱輸入欄；移除頂部資訊卡的農地數量節點。
- `src/game.js`：名稱輸入事件對非空、長度不超過 24 字且確實有變更的名稱立即更新遊戲狀態、存檔及頁面標題；離開輸入欄時收起編輯介面並還原至最近一次有效名稱。移除頂部農地數量節點對應的 JavaScript 引用。
- `src/styles.css`：移除頂部農地數量樣式；金幣數字桌面版由 14px 縮至 11px，手機版由 12px 縮至 10px。

## 靜態檢查
- 確認 HTML 已移除農地數量節點及名稱編輯按鈕。
- 確認 JavaScript 不再引用已移除的農地數量節點。
- 確認名稱輸入事件會即時存檔、離開輸入欄會結束編輯。
- 確認桌面及手機金幣字體規則均已更新。
- 尚未執行實際瀏覽器操作或手機視覺驗收；待驗收手機編輯名稱、刷新後名稱保留及頂部卡片排版。
