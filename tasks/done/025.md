# 任務 025：新增無人機澆水與限時生長加速

## 執行結果

農地操作視窗新增澆水按鈕。工作經由既有無人機 FIFO 佇列前往目標地，並以藍色水滴動畫呈現。每株作物可澆水一次；澆水後八秒內以兩倍速度累積生長，等同額外增加八秒有效生長時間。增益時鐘會保存；過期後轉為累積生長加成，舊存檔沒有澆水欄位時照常載入。

## 驗收

- [x] 可從農地視窗排入澆水工作並播放水滴效果。
- [x] 澆水使用單一無人機佇列。
- [x] 只加速指定作物八秒，效果為兩倍速度。
- [x] 面板、倒數、自動收成、模型階段及存檔使用一致的有效生長時間。
- [x] 空地、成熟花及已澆水作物不會重複套用；失效等待工作會略過。
