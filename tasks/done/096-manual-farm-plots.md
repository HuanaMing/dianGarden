# 任務 096：手動農地與無人機排除

## 目標

新增可切換的「手動農地」地塊屬性；此類地塊由玩家直接管理，無人機不會對其播種、澆水或收成。

## 驗收條件

- 地塊資訊面板提供手動農地開關，狀態可保存並於重載後保留。
- 開啟手動農地後，自動模式不會對該地塊派出任何工作。
- 手動農地的玩家操作不呼叫無人機任務；其他地塊維持現有行為。
- 資料遷移、待辦工作及切換時的執行中工作不會讓無人機操作手動農地。

## 執行結果

新增持久化的 `plot.manual` 布林欄位，舊存檔預設一般農地。地塊資訊面板新增開關；切為手動會取消該地塊等待中的工作，若無人機正執行工作則停用開關至工作完成。自動派工跳過手動農地，玩家在手動農地播種、澆水及收成時直接結算，不呼叫無人機動畫。切回一般農地後，若自動模式開啟會重新規劃派工。

未執行測試或瀏覽器操作（依專案指引）。
