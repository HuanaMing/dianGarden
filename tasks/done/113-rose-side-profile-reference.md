# 任務 113：依側面照片調整玫瑰花冠輪廓

## 目標

依使用者提供的玫瑰側面照片，讓成熟模型呈現飽滿圓潤的側面花冠與上翻外瓣。

## 驗收條件

- 側面可看出花托上方由低至高鼓起的花冠，不再像薄片。
- 花瓣保留同心錯位與旋卷花心，外緣略向上翻展。
- 自訂花色與綠色萼片維持有效，變更僅影響玫瑰成熟花冠。
- 記錄參考照片與實際幾何改動。

## 執行結果

依側面照片提高玫瑰花冠的立體高度：外瓣根部下沉至花托附近，再向上拱起至瓣脊與上翻瓣緣；往內各層逐步升高，形成低花托、圓鼓花冠及收攏花心的側面剖面。四層旋卷錯位排列、自訂花色與五片綠色萼片保留。

參考：使用者提供的 [KOSFARM 玫瑰側面照片](https://www.kosfarm.com.tw/wp-content/uploads/2022/02/%E7%8E%AB%E7%91%B0-scaled-e1646792462331.jpg)。
