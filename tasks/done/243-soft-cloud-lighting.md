# 任務243：降低雲朵光照明暗對比

## 需求
降低雲朵在光線下的明暗對比，讓雲體更柔和，避免過深的暗面與刺眼亮面。

## 範圍
- 將雲朵幾何的下側面色差由原本 0.78 的陰影係數提高至接近 0.92。
- 天空渲染採近乎均勻的光照，繪製完天空後恢復地塊原有光照參數。
- 保留雲朵位置、大小、飄動、透明度與晴雨顏色。

## 驗收
- 雲朵面與面之間的明暗差降低。
- 地塊及花卉仍使用原本日照／夜間光照。
- Playwright 規格與 JavaScript 語法檢查通過。
