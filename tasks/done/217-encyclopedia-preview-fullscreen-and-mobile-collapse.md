# 任務217：圖鑑預覽全螢幕與手機版收合

## 來源
使用者提出圖鑑花種預覽操作改善：預覽可以全螢幕；手機版選花時可收合預覽以增加選花空間。

## 工作範圍
- 在花種 3D 預覽區右下角新增全螢幕按鈕。
- 啟用後讓預覽擴展至全螢幕，並在預覽右下角提供退出全螢幕的控制。
- 優先使用瀏覽器 Fullscreen API；若環境不支援或請求失敗，提供合理且不破壞原版面的替代呈現方式。
- 手機版選花介面中，點擊「選擇花種」標題區可收合預覽，釋放選花清單空間。
- 使用者選擇花種後，恢復預覽與選花介面的原有排版。
- 保持桌面版既有圖鑑操作與模型互動不變。

## 不在範圍內
- 不重做花卉模型或改動花卉資料。
- 不引入新的前端套件。

## 預計檢查檔案
- `src/encyclopedia.html`
- `src/flower-encyclopedia.js`
- `src/styles.css` 及圖鑑專用樣式
- `tests/browser-smoke.mjs`

## 驗收條件
- 預覽右下角有全螢幕控制；啟用後預覽佔據可用全螢幕區域。
- 全螢幕狀態可透過右下角控制退出；瀏覽器不支援 Fullscreen API 時仍有可用替代方式。
- 手機版點擊「選擇花種」標題可收合預覽，再次點擊可展開（若採用切換式操作）。
- 手機版選擇花種後，介面恢復原排版且選擇結果正確。
- 桌面與手機版的模型旋轉、縮放及選花操作沒有回歸問題。
- 適當測試通過，或明確記錄無法驗證的部分。

## 執行結果
- 已更新 `src/encyclopedia.html`、`src/flower-encyclopedia.js` 與 `src/styles.css`，在預覽右下角加入全螢幕／退出控制。
- 優先使用 Fullscreen API；API 不可用或請求失敗時，改用固定定位的全視窗預覽，仍可透過同一按鈕退出。
- 手機版「選擇花種」標題可切換收合預覽；收合後選擇花種會自動恢復原排版。
- 已更新 `tests/browser-smoke.mjs`，桌面全螢幕與右下角按鈕位置、手機 fallback 全螢幕、收合／選花恢復均通過。
