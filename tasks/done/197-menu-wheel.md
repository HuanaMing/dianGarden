# 任務197：長按快捷輪盤重做與介面互斥

## 最新需求

1. 滑到輪盤「旋轉」方向時，立即收起輪盤並進入拖曳旋轉，不等待放開。
2. 手指／滑鼠放開或取消時，立即退出旋轉。
3. 移除各選項的可見 container／底板；滑到某個方向時，只放大該方向對應的 60 度花草環區段。
4. 花草環素材可見度為 100%。
5. 保留六個選項：無人機、農地管理、設定、圖鑑、收合／展開介面、旋轉；無人機／農地管理／設定面板互斥。

## 驗收條件與結果

- **通過**：長按空白場景約 500ms 顯示輪盤。
- **通過**：滑到旋轉區段的同一個 pointermove 事件即收起輪盤並開始旋轉；放開／pointercancel 後退出旋轉。
- **通過**：選項不顯示底板與邊框，中心透明；選取狀態會放大對應花草環區段。
- **通過**：花草環使用 `assets/wreath.webp`，opacity 100%、visibility visible。
- **通過**：地塊移動模式、雙指縮放及手機長按回饋回歸測試。
- **通過**：無人機、農地管理、設定三個面板互斥。
- **通過**：六個輪盤操作、按鈕素材、無障礙名稱及輪盤圖示尺寸／定位檢查。

## 實作紀錄

- `src/sky-world.js`：滑到旋轉方向即收起輪盤、開始旋轉；同一指標放開或取消後退出，移除原本長按空地直接旋轉的舊流程。
- `src/styles.css`：移除選項底板與邊框，選取時放大對應 60 度花草環區段，素材 opacity 設為 1 且 visibility visible。
- `src/index.html`：保留六個輪盤操作及無障礙屬性；四個 PNG 圖示另使用獨立覆蓋層，避免扇形裁切。
