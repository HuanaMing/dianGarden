# 任務 183：設定面板版本資訊與立即更新

## 狀態
已完成

## 目標
在設定面板顯示目前版本號、伺服器最新版本號，並提供「立即更新」按鈕。

## 需求
- 設定面板顯示「目前版本號」與「最新版本號」。
- 加入「立即更新」按鈕。
- 按下立即更新時，達到接近 Ctrl+F5 的強制更新效果：重新取得最新 HTML，並為同源 CSS、JavaScript 等靜態資源加入 cache-busting query，避免沿用舊快取。
- 瀏覽器不允許 JavaScript 直接觸發真正的 Ctrl+F5，因此以 no-store 重新抓取頁面、更新同源資源 URL 後重新載入文件來達成等效流程。
- 立即更新前保存目前遊戲狀態；更新失敗時顯示錯誤，不可清除或重置存檔。
- 更新提示中的「重新載入」也應使用同一個強制更新流程，避免兩種更新入口行為不一致。
- 保留既有 version.json 格式及自動檢查行為。

## 驗收條件
- 設定面板中能看見目前版本號、最新版本號及立即更新按鈕。
- 版本檔可用時顯示最新版本；網路失敗時不阻擋遊戲，且 UI 清楚顯示無法取得最新版本。
- 點擊立即更新會以 `cache: no-store` 取得最新 HTML，並對同源 CSS、JavaScript 及圖片資源加入更新查詢參數，再重新解析文件。
- 更新過程不清除遊戲存檔；更新失敗時仍能繼續使用目前遊戲。
- Playwright 自動驗收涵蓋版本資訊 UI 與立即更新的 cache-busting 行為，既有回歸測試通過。
- 更新架構文件、任務狀態與工作歷史。
