# 任務 065：新增重置遊戲進度按鈕

## 順序
第四項，依賴任務 064 完成。

## 目標
新增清楚可見的重置進度操作，讓玩家能將花園恢復成新遊戲狀態。

## 實作範圍
- 在現有遊戲介面加入重置按鈕，樣式與位置需適合窄螢幕及桌面版。
- 執行前顯示確認對話框，明確說明金幣、花園名稱、土地、作物、無人機和設定都會恢復初始值。
- 確認後清除本遊戲存檔並載入乾淨的新遊戲狀態；取消時不改變任何狀態。
- 重新載入或重建世界時同步重置 3D 場景與 HUD，不保留舊工作或活動動畫的結果。

## 驗收條件
- 玩家可取消確認，原進度完整保留。
- 確認後所有遊戲資料恢復初始狀態，頁面重新載入後仍為新遊戲。
- 重置不影響其他網站的 localStorage 資料；儲存失敗時提供明確提示。
- 桌面與窄螢幕都可找到並操作按鈕及確認視窗。
## 完成結果
已在場景右上新增重置按鈕與逐項列明刪除範圍的確認對話框。取消不修改資料；確認只移除遊戲存檔鍵並重載，重置期間阻擋離場／動畫回呼存檔；儲存存取失敗時顯示提示。

## 驗收
Edge 無頭瀏覽器成功載入遊戲與右上重置按鈕（BrowserExit=0）。DevTools WebSocket 無法連線，未能互動點擊確認／取消；程式流程已檢視。其餘三項飛行／場景功能亦已在同一瀏覽器載入畫面檢查，交互時序以回呼及狀態流程檢視。

狀態：已完成。
