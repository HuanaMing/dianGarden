# 任務 270：無人機電量指示與奶油色中央光源

## 目標
將無人機電量顯示改為機身正面偏右、沿 Y 軸排列的四個暖橘色扁長方形亮點；機身可見度調整為 70%；移除八面體隨電量改變顏色的機制，將八面體移至機身中心並使用月光般的奶油色，光強度隨電量降低。

## 實作規格
1. 四個暖橘色指示燈沿 Y 軸垂直排列，放在無人機正面偏右。
2. 電量區間：75–100% 亮 4 個；50–<75% 亮 3 個；25–<50% 亮 2 個；10–<25% 亮 1 個；0–<10% 亮 0 個。實作時以 75、50、25、10 作為各級下限。
3. 只有無人機主機身透明度固定為 70%；翅膀木框、翅膀窗面及其他非機身零件維持 100% 可見度。機身透明度不受日夜、天氣或光照變化影響。
4. 移除舊的電量漸層八面體；在機身中央清楚顯示固定月光奶油色八面體，並讓周圍無人機光源強度依電量 0–100% 線性變化。
5. 不改動其他無關功能、不安裝新依賴、不觸發部署。
