# 任務214：固定無人機管理版面與四欄網格

## 來源
使用者提出無人機管理介面優化。

## 工作範圍
- 無人機管理面板在佇列任務數量變動時，維持固定且穩定的整體尺寸，避免內容增減造成面板跳動。
- 無人機列表改為每行四台，以圓角正方形卡片呈現。
- 將面板剩餘空間預留給任務佇列；佇列內容超出可用空間時，裁切／隱藏超出部分，避免推大面板。
- 佇列區需保留合理的可讀性，且不得遮擋必要操作。

## 預計檢查檔案
- `src/index.html`
- `src/styles.css`
- `src/management-panels.css`
- 無人機清單與任務佇列的渲染程式
- `tests/browser-smoke.mjs`

## 驗收條件
- 佇列從少量增加至超出顯示空間時，面板外框大小不變。
- 無人機卡片以四欄排列，外觀為圓角正方形；不同無人機數量下排列穩定。
- 佇列只佔用分配的區域，超出部分不會撐開面板或擠壓無人機網格。
- 桌面與手機版皆無重疊、溢出或重要控制被遮住。

## 執行結果
- 已更新 `src/management-panels.css`：無人機管理面板使用固定高度與 flex 直向排版，外框不受佇列數量影響。
- 無人機列表改為四欄網格，卡片維持正方形比例，狀態文字限制行數並避免內容撐大卡片。
- 工作佇列佔用面板剩餘空間；超出可用高度的項目由 `overflow:hidden` 隱藏，不會撐開面板。
- 已更新 `tests/browser-smoke.mjs`，驗證四欄網格、卡片正方形、面板前後尺寸一致，以及佇列溢出時維持隱藏。
