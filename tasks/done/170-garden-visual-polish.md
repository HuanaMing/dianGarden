# 任務 170：花園整體視覺層次升級

## 目標
改善花園場景的整體閱讀性與自然感，維持輕量原生 WebGL 架構與既有操作方式。

## 設計原則
- 以低風險局部調整改善地表層次。
- 不更動花種索引、花卉資料、遊戲數值、存檔格式、土地拼接及無人機工作規則。
- 保持桌面與手機操作可用，並注意 WebGL 每影格效能。

## 修改與驗收
- [x] 明確記錄可觀察的視覺問題：不同地塊土壤紋理原本使用相同固定方向，草地色斑只比基色更亮。
- [x] 完成局部視覺調整：土壤紋理依地塊座標穩定旋轉，草地色斑加入適度明暗差。
- [x] 十一種花卉模型均仍能正常切換與繪製（Playwright 瀏覽器驗收成功）。
- [x] 桌面、手機首頁及花卉圖鑑瀏覽器驗收通過。
- [x] 未更動遊戲數值、存檔格式、土地操作或無人機規則。
- [x] 保存修改後截圖並人工檢視首頁畫面；地塊土壤紋理方向有變化，草地斑塊有明暗差。這次未保存修改前基準，因此無法量化前後差異。

## 實作紀錄（2026-10-22）
- `src/sky-world.js` 的 `addSoilTexture()`：使用地塊 X/Z 座標計算可重現的旋轉角度，同步旋轉土壤紋理標記的位置與方向，避免重複圖案且不引入隨機閃爍。
- `addGrassTexture()`：草地色斑亮度倍率由 `1.025–1.11` 改為 `0.94–1.13`，增加適度深淺變化。
- 不增加幾何數量，不修改玩法資料或操作規則。
