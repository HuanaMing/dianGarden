# 任務 058 重作 1：多機並行派工、避碰與地塊工作卡住修正

## 目標
讓多台已部署無人機能同時接取自動／手動工作，避免互相穿模；修復首台無人機接近中央地塊時工作卡住，導致地塊不能刪除、成熟植物不能手動收成的問題。

## 完成項目
- 以 `activeJobs` 按無人機索引管理活動工作；不同無人機可以同時作業，同一地塊不會被重複派工，擴建工作獨占執行。
- 每台無人機採用獨立動畫狀態及分層巡航高度，逐影格檢查距離並在衝突時側移或暫停。
- 碰撞檢查只納入已購買且已部署的無人機。此前未購買的預配置槽位被錯誤視為無人機，並在 `(0, 0)` 阻擋飛往中央地塊的路線，使工作永不結束；修正後首台無人機可正常完成任務並釋放地塊鎖定。
- 手動收成和自動工作都由同一派工器處理；工作完成後清除活動狀態，地塊操作恢復可用。
- 移除瀏覽器驗收期間加入的臨時存檔注入程式碼。

## 驗收結果
Edge 無頭瀏覽器畫面驗收到三台無人機同時顯示播種不同地塊，且各自有獨立飛行狀態與停靠坪台。檢查碰撞判定後確認未購買槽位不再阻擋中央地塊工作。手動收成仍由既有成熟狀態檢查與 `harvest` 派工流程執行；清除活動工作後可再次操作土地。
