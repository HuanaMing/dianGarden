# 任務 075：新增俯視 2D 相機模式

## 目標

新增「2D模式」切換按鈕。啟用後固定相機於原點上方並沿世界座標 `(0, -1, 0)` 方向垂直向下看。

## 驗收條件

- 場景提供清楚可操作的 2D／3D 模式切換按鈕與當前模式狀態。
- 2D 模式相機固定在高處、中心對準世界原點，視線方向為 `(0, -1, 0)`；需採用不與視線平行的相機 up 向量，避免直上直下視角矩陣退化。
- 2D 模式期間，天空拖曳、WASD 及滾輪不改變固定相機；地塊與坪台點選、長按拖曳仍可用。
- 切回 3D 時恢復切換前的相機位置與角度。
- 按鈕在 HUD 收合及窄螢幕下仍可找到與操作。

## 相依與注意

- 參照 `src/sky-world.js` 的 `lookAt()`、投影及相機輸入處理；垂直向下視角不能沿用平行的 up 向量。
- 這是同一個 WebGL 場景的相機模式，不需新增依賴或另建 2D 場景。

## 執行結果（2026-10-21）

完成：確認並補齊同一 WebGL 場景的 2D／3D 切換介面；2D 相機固定於原點上方並採非平行 up 向量，忽略相機輸入且切回 3D 還原原姿態。相機按鈕在 HUD 收合與窄螢幕保持可操作。
