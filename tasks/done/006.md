# 任務 006：連結 3D 島嶼與農地選取

## 目標

讓玩家可在 3D 場景與農地卡片間辨識並選取同一塊土地。

## 限制

- 使用瀏覽器原生 WebGL 與 DOM API，不加入外部套件。
- 保留 WebGL 不可用時仍可操作農地卡片的行為。
- 不修改工作區以外的檔案。

## 驗收標準

- [x] 點擊 3D 土地方塊會選取對應農地，並以金色框標示。
- [x] 點擊農地卡片或其選取按鈕會高亮對應 3D 土地。
- [x] 土地編號與兩種介面的索引一致，新開墾土地可映射。
- [x] 滑鼠及觸控可選取；超過 5 像素的拖曳才會旋轉相機。
- [x] WebGL 不可用時，農地卡片仍可選取和操作。

## 狀態

已完成（尚未進行瀏覽器手動驗收）。

## 執行紀錄

- 新增土地方塊表面投影選取，將點選映射到現有農地索引。
- 選取時在 3D 方塊周圍繪製金色框，並同步更新農地卡片的選取狀態。
- 加入農地卡片選取按鈕，並以 5 像素移動門檻區分輕點和相機拖曳。
- 保留 WebGL 不可用時的 DOM 卡片互動。
- 未執行瀏覽器手動驗收。
