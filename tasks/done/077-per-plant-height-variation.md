# 任務 077：花卉植株高度加入穩定浮動

## 目標

讓每株花卉模型的高度在其原始高度的 0.9 至 1.1 倍之間變化。

## 驗收條件

- 每次播種為該株作物產生 0.9–1.1 之間的高度倍率，幼苗與成熟模型依同一倍率縮放。
- 倍率隨地塊存檔並在重繪、重新載入及澆水／收成 UI 更新時保持不變，不會每影格跳動。
- 舊存檔未含倍率時按原始高度 1.0 顯示；不影響生長時間、收成或花種索引相容性。
- 十種花卉各自的原始高度維持目前 `src/sky-world.js` `flowerHeights` 定義。

## 相依與注意

- 將倍率存於作物地塊資料，不要改動全域花種高度或整個地塊尺寸。
- 圖鑑應顯示原始模型高度及其 0.9–1.1 倍範圍，避免把單株隨機高度誤當作花種基準高度。

## 執行結果（2026-10-21）

完成：每次播種保存 0.9–1.1 的 plantHeight，幼苗與成熟模型共用倍率；舊存檔作物缺值時設為 1.0，澆水或介面重繪不重新抽樣。遊戲與圖鑑高度資料改讀共用目錄。
