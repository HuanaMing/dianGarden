# 任務 013：加入土地拖曳拼接與位置保存

## 目標

玩家可選取一塊土地並拖動，在 3D 場景中自由調整位置，並讓土地邊緣可相鄰拼接。

## 前置任務

- 任務 011：確定主要土地互動與替代介面均位於 3D 場景區域。

## 限制

- 使用現有 WebGL 場景及原生指標／觸控事件，不加入外部 3D 套件。
- 土地位置應吸附到一致網格，避免重疊；合法位置可連接現有土地群。
- 拖曳土地與旋轉相機的手勢必須可區分。
- 位置資料需保存並驗證；舊存檔沒有座標時要自動產生原本的預設排列。

## 驗收標準

- [x] 可用滑鼠或觸控選取並拖動單一土地，拖動時有清楚的預覽或高亮。
- [x] 放開時吸附至網格，土地不重疊，合法土地可與既有土地邊緣相接。
- [x] 拖曳土地不會誤觸選地或旋轉相機；點擊及相機拖曳原操作仍有效。
- [x] 重新載入後土地位置保持；舊版存檔能自動沿用預設排列。
- [x] 不合法位置會回復至最後有效位置並提示原因。
