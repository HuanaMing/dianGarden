# 任務225：修正多台無人機異常瞬移

## 類型
Bug 修正

## 問題描述
無人機數量較多時，部分無人機會出現不正常的瞬間位移，破壞飛行動畫與工作狀態的連續性。

## 調查範圍
- 檢查每台無人機是否正確維持獨立的動畫狀態、目前路徑、航點索引、飛行進度及目標位置。
- 檢查派工、前往工作地點、作業、返航、停靠、等待佇列及接續下一個任務時的狀態切換。
- 檢查無人機數量變化、收起／放出、停靠位置更新、場景重繪與存檔載入時，陣列索引或物件參照是否錯位。
- 檢查路徑插值、航點切換、避障及起降高度是否在特定條件下突然重設。
- 依實際程式流程定位根因，不預設問題只出在繪圖或派工其中一側。

## 修改原則
以每台無人機自身的狀態與路徑為準，避免不同無人機共用或錯用可變動畫資料。修正時維持現有派工規則、路徑避障、電量管理、工作佇列與存檔相容性；避免為了平滑畫面而延誤或遺失工作。

## 驗收條件
- 1 台無人機時，原有移動與工作流程正常。
- 2～4 台及最大 8 台無人機同時待命、派工、作業、返航或排隊時，不會發生非預期瞬移。
- 無人機從停靠位置起飛、沿路徑移動、抵達工作地點、返航及接續下一個任務時，位置連續且目標正確。
- 收起／放出無人機、切換場景狀態或重新載入存檔後，不會因索引或狀態殘留造成瞬移。
- 執行可用的自動化回歸測試；若需要實際觀察動畫才能驗收，應明確記錄是否已完成瀏覽器視覺驗收。

## 執行紀錄
- 根因定位：`src/game.js` 每秒更新無人機電量並呼叫 `setDroneDocks()`；原本只要停靠資料有任何變動（包含電量）就會重算返航中的 `returnRoute`。多台無人機時，路徑長度及航點會隨其他無人機位置變化而反覆改寫，但動畫 elapsed 仍沿用舊進度，導致同一進度映射到新路徑後出現位置跳變。
- 修正：`src/sky-world.js` 現在會先比較各台無人機的停靠 X/Z 座標，只有停靠位置實際改變時才更新動畫的停靠目標／返航路徑；單純電量、部署狀態或其他欄位更新不再重設返航插值路徑。
- 回歸檢查：`tests/browser-smoke.mjs` 加入來源斷言，確保返航路徑重算受停靠座標變化條件保護。
## 驗收結果
- `src/sky-world.js`、`src/game.js`、`src/version-check.js`、`src/cloud-save.js` 與 `tests/browser-smoke.mjs` JavaScript 語法解析均通過。
- 新增八台無人機的瀏覽器回歸測試：同時啟動工作動畫、連續更新電量資料，取樣 WebGL 無人機頂點位置，檢查相鄰取樣是否有大幅跳位。
- GitHub Actions Playwright 桌面／手機完整驗收通過：[run 40169170602](https://github.com/HuanaMing/dianGarden/actions/runs/40169170602)。八台無人機測試取得 70 個位置取樣，最大相鄰取樣位移為 0.080 世界單位，低於 0.8 的異常跳位門檻。
- 既有停靠位置變更仍會更新返航目標；僅電量等非位置欄位更新不再重算返航路徑。
