# 任務 98：細化向日葵模型

## 目標

細化遊戲中的向日葵 3D 模型，提升花型辨識度並維持低多邊形風格與自訂顏色支援。

## 驗收條件

- 修改限於向日葵與必要共用幾何輔助，不改變其他花種外觀。
- 成熟模型呈現該花種代表性的花型、花瓣／小花層次及必要葉片特徵。
- 執行結果記錄實際幾何改動及有使用時的形態參考來源。

## 執行結果

完成向日葵花盤細化：新增兩層共 20 枚扁長舌狀花、螺旋排列的 48 顆深色盤花小花，以及花盤背部綠色苞片；花瓣色仍取自花種／變種顏色。形態參考：[Cornell CALS](https://cals.cornell.edu/weed-science/weed-profiles/common-sunflower) 與 [Iowa State Extension](https://yardandgarden.extension.iastate.edu/how-to/perennial-sunflowers-home-landscape) 對外圍舌狀花和中央盤花的說明。

未執行測試或瀏覽器操作（依專案指引）。
