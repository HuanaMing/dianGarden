# 任務 092：重作任務 080 變種播種選單

## 目標

將已保存的花色變種放入手動播種原始花種的下拉選單，依所屬花種分組選擇。

## 驗收條件

- 手動播種時可在原始花種的下拉選單內選擇該花種的自訂變種。
- 選擇變種後能正確扣除基礎花種成本、保存變種 ID 並種下對應花色。
- 原始花種、自動選種、自動播種行為維持不變。

## 執行結果

已將手動播種介面改為依原始花種分組的下拉選單，該花種的自訂變種列在同一群組。選取時顯示花名、種子價格、生長時間及收成資訊；確認按鈕檢查金幣並沿原播種流程傳遞變種 ID。自動選種及自動播種資料流未變更。

未執行測試或瀏覽器操作（依專案指引）。
