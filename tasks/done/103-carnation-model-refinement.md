# 任務 103：細化康乃馨模型

## 目標

細化遊戲中的康乃馨 3D 模型，提升花型辨識度並維持低多邊形風格與自訂顏色支援。

## 驗收條件

- 修改限於康乃馨與必要共用幾何輔助，不改變其他花種外觀。
- 成熟模型呈現該花種代表性的花型、花瓣／小花層次及必要葉片特徵。
- 執行結果記錄實際幾何改動及有使用時的形態參考來源。

## 執行結果

康乃馨花頭改為三層交錯花瓣扇片，外緣以三段不等長尖齒做出褶皺流蘇效果，中心保留緊密花瓣。花瓣色沿用變種色。形態參考：[NC State Extension](https://plants.ces.ncsu.edu/plants/dianthus-caryophyllus/common-name/border-carnation/) 對康乃馨重瓣皺褶花瓣的描述。

未執行測試或瀏覽器操作（依專案指引）。
