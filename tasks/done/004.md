# 任務 004：重設作物種類為花卉

## 目標

將種植種類改為向日葵、風信子、鈴蘭與玫瑰，建立各自的 3D 模型、相對花卉尺寸及不同生長速度。

## 背景

希望農場以常見花卉為主題。

## 限制

- 使用原生 HTML、CSS、JavaScript，不加入外部套件。
- 花卉設定集中定義。
- 不修改工作區以外的檔案。

## 驗收標準

- [x] 可選擇向日葵、風信子、鈴蘭與玫瑰。
- [x] 每種花卉都有獨立的低多邊形模型，尺寸呈現常見植株的相對高度。
- [x] 每種花卉設定不同生長速度，倒數、進度、成熟判斷與 3D 階段一致。
- [x] 舊存檔索引 0、1、2 分別對應向日葵、風信子、鈴蘭；新索引 3 為玫瑰，既有種植時間與農地資料保留。
