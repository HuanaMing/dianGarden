# 任務 99：細化風信子模型

## 目標

細化遊戲中的風信子 3D 模型，提升花型辨識度並維持低多邊形風格與自訂顏色支援。

## 驗收條件

- 修改限於風信子與必要共用幾何輔助，不改變其他花種外觀。
- 成熟模型呈現該花種代表性的花型、花瓣／小花層次及必要葉片特徵。
- 執行結果記錄實際幾何改動及有使用時的形態參考來源。

## 執行結果

成熟風信子穗狀花序改為 6 層、共 22 朵小花；每朵以六裂外張花被片和小型花心構成，沿用原花色。花序向頂端收窄以保持密集圓柱輪廓。形態參考：[NC State Extension](https://plants.ces.ncsu.edu/plants/hyacinthus-orientalis/) 對單一直立圓柱狀總狀花序與六裂漏斗狀花的描述。

未執行測試或瀏覽器操作（依專案指引）。
