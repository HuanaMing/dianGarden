# 任務241：無人機尋路避開延伸到底部的地塊側牆

## 需求
無人機尋路時，必須把地塊側向延伸到底部的牆面視為障礙，不能再讓水平航線穿過牆體。

## 範圍
- 在既有 A* 尋路中，把地塊側牆所占據的水平區域加入障礙判斷。
- 起點地塊與目的地地塊不應阻止無人機離開或抵達。
- 保留其他無人機避障、對角線防切角、航線平滑度及工作流程。
- 不修改地塊幾何、存檔格式或無人機玩法。

## 驗收
- 航線節點避開其他地塊的側牆區域。
- 無人機可從起點正常離開，並可抵達目的地地塊。
- Playwright 規格測試包含側牆避障檢查。
