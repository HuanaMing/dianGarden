# 任務196：修正農地坡面草皮與植物中心附著

## 需求
1. 農地變形時，確保綠色草地表面不會從種植土壤床上方或邊緣穿出。
2. 農地與草地變形時，植物根部必須附著於該地塊實際可見的中心表面高度。

## 修改範圍
- `src/sky-world.js`：區分草地與農地頂面呈現；統一計算地塊中心表面高度；讓農地土壤紋理跟隨坡面。
- `tests/browser-smoke.mjs`：增加農地坡面中心高度與植物基準高度的回歸檢查。
- `docs/architecture.md`：記錄修正後的地表及植物附著規則。
- 狀態與工作歷史紀錄。

## 驗收條件
- 純草地仍呈現綠色坡面與草地紋理。
- 農地保留綠色草皮與草地紋理；草皮位於土壤床下方，不能高於土壤床頂面。
- 農地土壤床頂面中心高度可作為植物根部基準；草地植物仍附著在草地坡面中心。
- 土壤紋理各頂點依坡面高度放置，不以單一水平高度穿過土壤床。
- 混合地塊共用角點、既有斜坡測試及 Playwright smoke test 通過。

## 執行結果
- 農地坡面保留綠色草皮與草地紋理；只有純草地繪製綠色草地斑紋，避免農地邊緣外露綠草。
- 土壤床中心高度改為坡面中心高度加上床厚度，避免以四角平均造成非對稱坡面中心高度偏移。
- 植物模型基準改為補償模型內部的 0.055 高度偏移，使根部貼齊草地地表或農地土壤床頂面；種子模型下移 0.02，讓種子底部與根部基準一致。
- 土壤紋理的每個頂點依坡面高度放置。
- 新增 Playwright 回歸檢查，涵蓋植物根部中心高度及坡面呈現規則。
- GitHub Actions Playwright 通過：[run 40065297350](https://github.com/HuanaMing/dianGarden/actions/runs/40065297350)。
- 尚未人工檢查實際遊戲畫面。
