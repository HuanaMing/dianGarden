# 任務 088：雨水更新植物澆水狀態

## 目標

降雨結束後將雨水視為一次自然澆水；已有澆水紀錄不阻止雨水濕潤，未澆過水的植物則記為已澆水。

## 驗收條件

- 雨停時所有已種下的作物獲得雨水濕潤狀態和雨後水滴動畫。
- 未曾澆水的作物更新 `watered`、澆水起訖時間，並受一次性澆水限制保護。
- 已澆水作物仍能被雨水刷新濕潤效果；既有加速先結算，不重複或遺失生長加成。
- 收成、重播種、自動澆水、手動澆水和存檔載入正確保留新狀態。

## 執行結果

- 完成：在遊戲保存的 `lastObservedRaining` 偵測雨停（包含重新載入時跨越雨停）；對所有已種下作物逐一標記已澆水，並於雨停時開始新一段 `waterUntil` 濕潤效果。
- 完成：雨水可刷新已澆水作物；覆寫舊水潤期限前先把已累積的 1.2 倍生長加成結算至 `growthBonusMs`，避免重複計算或遺失加成。
- 檢視：存檔欄位向後相容、雨停轉換去重、手動／自動澆水門檻、舊加成結算及雨中粒子暫停；未執行測試或瀏覽器操作（依專案指引）。
