# 任務192重做：草地斜坡側面跟隨頂面變形

## 需求
草地頂面已經依相鄰地塊產生斜坡，但地塊周圍四側仍使用未跟隨頂面角點的側面幾何，導致頂面與側面看起來像兩個不同形狀。修正側面網格，使四周側面上緣與草地頂面使用相同角點高度，讓側面隨坡面一起變形。

## 實作結果
- 保留四向鄰居判定：只連接正交相鄰一格，且高度差不超過 0.5；不採用對角線。
- 新增 `getCornerHeights()`，以相鄰兩側邊緣高度推導每個角點高度。
- 頂面坡面、側面上緣及表面高度取樣共用同一組角點高度，側面不再各自維持平坦的頂邊。
- 保留地塊厚度、底面及既有草地材質。

## 驗收結果
- GitHub Actions Playwright 瀏覽器自動驗收通過。
- 四邊高度差 -0.5、0、+0.5 的 81 種排列通過。
- 側面角點高度的 81 種組合測試通過。
- 對角線、距離超過一格及高度差超過 0.5 的連接限制回歸測試通過。
- 任務191離線模擬核心邊界及既有遊戲回歸測試通過。
- 自動驗收工作流程：https://github.com/HuanaMing/dianGarden/actions/runs/40063305945

已驗證網格使用一致角點高度的數學規則並通過瀏覽器自動測試；未人工逐像素檢查所有地形截圖，因此不把這項結果描述為人工視覺驗收。
