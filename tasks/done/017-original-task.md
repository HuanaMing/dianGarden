# 任務 017：建置無人機停靠站

## 目標

在空島上加入清楚可見的無人機停靠站，讓無人機完成工作後回到停靠站待命。

## 前置任務

- 任務 016：讓無人機成為持續存在的場景實體。

## 限制

- 使用原生 WebGL 幾何及現有空島座標系統。
- 停靠站不得覆蓋、移動或阻擋玩家農地。
- 返回停靠站應是工作動畫的一部分；停靠狀態與閒置狀態需視覺可辨。

## 驗收標準

- [ ] 場景中有外觀明確、固定且不與農地重疊的停靠站。
- [ ] 無人機執行播種或擴建後飛回停靠站。
- [ ] 抵達後停在站上或其上方，螺旋槳切換為低速待命動作。
- [ ] 土地數增加或位置改變時，停靠站仍在有效可見位置。
