# 任務 180：日夜天氣漸變與點擊回饋時序

> 狀態：已完成並通過 GitHub Actions 瀏覽器驗收（2026-10-23）

## 完成內容

### 1. 日夜交替漸變
- `src/sky-environment.js` 新增日照漸變進度，日出與日落以 60 秒、每秒線性更新的方式從夜晚過渡至白天／從白天過渡至夜晚。
- `src/sky-world.js` 依日照進度逐秒混合天空漸層色，保留日出與日落的暖色調；環境亮度同步更新。
- 保留原有日夜週期與存檔格式。

### 2. 晴雨交替漸變
- 天氣視覺只在晴雨狀態交替前最後 5 秒漸變。
- 雨景在預定降雨開始前 5 秒淡入，並在降雨結束前 5 秒淡出。
- 視覺漸變與遊戲規則中的 `isRaining` 分離；不提前觸發自然濕潤、澆水限制或其他遊戲邏輯。

### 3. 點擊位置回饋
- 點擊提示改為半透明 `#9CC9D9`，尺寸 76×76 px，約為長按環形半徑的 80%。
- 提示在 0.5 秒內淡出。

### 4. 環形長按計時器
- 指標按下時立即建立並啟動環形進度動畫，但延遲 200 ms 才顯示。
- 若在顯示前放開或移動，會取消計時環的顯示，不會短暫閃現。
- 保留原本 500 ms 長按判定，延遲只影響視覺顯示，不影響操作計時。
