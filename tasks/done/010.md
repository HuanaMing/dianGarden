# 任務 010：調整向日葵花朵朝向

## 目標

修改向日葵 3D 模型，讓花盤朝水平方向面向，而非朝上。

## 背景

目前向日葵花盤朝天空，使用者希望花朵面向水平方向。

## 限制

- 使用原生 WebGL 幾何，不加入外部模型或套件。
- 保留現有向日葵植株尺寸與成長階段切換。
- 不修改工作區以外的檔案。

## 驗收標準

- [x] 向日葵成熟花盤的正面法線沿水平方向，花瓣與中心盤可辨識。
- [x] 向日葵莖葉與花盤位置連接，模型不穿入土地。
- [x] 從預設相機視角可看見花盤正面，旋轉場景仍呈現正確的立體朝向。
- [x] 種子及幼苗階段不受此次模型調整影響。
