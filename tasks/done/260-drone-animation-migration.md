# 任務260：逐步替換無人機工作動畫交接

## 狀態
待執行；依賴任務259。

## 目標
讓飛行與工作動畫只呈現任務／狀態機／位置控制器的結果，不自行改派任務、提交遊戲結果或重設世界座標。

## 範圍
按順序遷移並逐一驗收：
1. 待命與前往地塊。
2. 抵達工作位置及工作高度銜接。
3. 播種動畫與結果提交。
4. 澆水動畫與結果提交。
5. 採收動畫與結果提交。
6. 返航、停靠及充電交接。
7. 同地塊連續任務與多機並行。

每一類動畫完成測試後才遷移下一類；移除舊回呼前需確認所有呼叫者已改接新契約。

## 驗收條件
- 動畫層不再直接改寫無人機世界座標或派發新任務。
- 播種→澆水、澆水→採收、採收→返航均從當前位置連續銜接。
- 工作結果回呼重複觸發不造成重複遊戲結果。
- 單機及最多 8 台無人機都能完成工作與返航。
- 工作特效、花卉高度、機身朝向與既有視覺表現沒有明顯回歸。
- 每一遷移步驟均有針對性測試及提交紀錄。
