# 任務 151：濕潤水滴漸入漸出循環

## 目標
將植物周遭水滴動畫改為循環的漸入、漸出，不再以位置上飄表現動畫。

## 範圍
- 以時間控制水滴透明度，形成連續的淡入／淡出循環。
- 不同水滴使用錯開相位，避免同時亮起或消失。
- 與任務 150 的固定位置設計整合。
- 濕潤狀態結束時停止顯示，不改變澆水及成長規則。

## 驗收條件
- 水滴位置不因淡入淡出而上下漂移。
- 透明度平順循環，無明顯閃爍或突然跳變。
- 多顆水滴的節奏略有錯開。
- 濕潤效果結束後所有水滴消失。

## 驗證
檢查時間函式、透明度計算及狀態結束分支。執行可用的 JavaScript 語法檢查；未執行瀏覽器視覺驗收時須註明。

## 狀態
進行中；依賴任務 150（固定水滴位置已完成程式修改）。


## 執行結果
- 為濕潤水滴加入獨立的透明度頂點資料與 WebGL 混合繪製。
- 每顆水滴以不同相位循環漸入漸出，位置維持任務 150 設定的固定座標。
- 其他場景特效維持不透明；效果繪製時暫停深度寫入，結束後恢復。

## 驗證結果
- `src/sky-world.js` JavaScript 語法編譯檢查：通過。
- 未執行瀏覽器視覺驗收；WebGL shader 的實際編譯及透明混合效果仍需在瀏覽器確認。

## 狀態
程式修改與靜態檢查完成，視覺驗收待確認。
