# 任務 011：將遊戲介面收整至中央 3D 區域

## 目標

移除中央 3D 場景以外的遊戲操作與資訊介面，讓玩家在空島場景內完成選地、種植、收成、擴建及查看金幣等操作。

## 前置任務

- 無；本任務是本輪第一項。

## 限制

- 使用現有原生 HTML、CSS、JavaScript 與 WebGL 架構。
- 主要操作視覺與互動必須位於中央 3D 區域或覆蓋其上的介面。
- WebGL 不可用時，將必要操作替代入口放在同一場景框內。
- 保留鍵盤、觸控及螢幕閱讀器可用性；不得只靠顏色傳達狀態。

## 驗收標準

- [x] 移除 3D 區域外的農地卡片、農場摘要及非必要遊戲操作區。
- [x] 金幣、農地狀態、選地操作及情境視窗都能在中央場景或其覆蓋介面中使用。
- [x] WebGL 不可用時仍可在中央場景框內完成完整遊戲操作。
- [x] 桌面、窄螢幕、鍵盤及觸控操作仍可使用，焦點狀態清楚。

## 狀態

已完成；WebGL 降級提示也已改為指引使用場景內農地快捷按鈕。未執行瀏覽器手動驗收。
