# 任務 148：手機拖曳防誤選文字與圖鑑維持網頁 App 模式

## 需求
1. 手機長按、拖曳場景或操作介面時，不應誤觸瀏覽器文字選取及系統長按文字選單。
2. 以主畫面／獨立視窗方式啟動的網頁 App 開啟花卉圖鑑時，應盡量維持獨立 App 顯示，不因頁面導覽切回帶網址列的瀏覽器介面。

## 修改範圍
- `src/styles.css`：停用頁面文字的選取與 iOS 長按呼叫選單；輸入欄位保留文字選取及編輯。
- `src/index.html`、`src/encyclopedia.html`：加入行動網頁 App capability meta 標記，讓支援的主畫面獨立啟動模式套用於兩個同源頁面。

## 驗收條件
- 手機長按並拖動 3D 場景或可拖曳物件時，不會反白選取頁面文字。
- 花園名稱、變種名稱等輸入欄仍可正常編輯與選取文字。
- 從已安裝／加入主畫面的獨立 App 開啟花卉圖鑑後，仍維持獨立視窗呈現，不出現瀏覽器網址列。

## 結果與限制
- 已提交 CSS 與兩個 HTML 頁面的修改。
- 靜態檢查可確認 CSS 規則與 meta 標記存在；尚未在 iOS／Android 實機測試。
- 網頁標記只能讓支援的平台在以主畫面／安裝 App 模式啟動時採用 standalone 顯示；若從一般瀏覽器分頁開啟，網址列仍由瀏覽器控制。iOS 與 Android 的安裝及導覽行為亦可能依系統版本而異。
