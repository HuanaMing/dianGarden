# 任務 166：薰衣草專屬莖葉與三根花莖

目標：為薰衣草（花種索引 8）建立專屬莖葉模型。每株成熟薰衣草有三根可辨識的花莖，三根莖各自採用不同的自然彎曲曲線，整體造型參考 `assets/` 中的薰衣草像素圖。

建模方向：
- 先檢查並參照 `assets/` 內薰衣草像素圖的整體輪廓、花穗分布與莖葉比例；不得臆測不存在的素材路徑。
- 一株薰衣草由三根細長花莖組成，三根莖略微分開，不要重疊成單一粗莖。
- 三根莖使用不同曲線：一根大致直立但略向一側彎、一根中段弧形外彎、另一根呈較明顯的反向柔彎；彎曲須連續平滑，不做生硬折角。
- 每根花莖頂端各有一根細長、紫色層次分明的薰衣草花穗，花穗方向跟隨各自莖梢的切線，形成三個不同方向。
- 葉片以薰衣草狹長、線形、成對或輪生的特徵為主，沿基部與下段莖節排列，避免寬卵形葉片。
- 幼苗維持簡化、低矮的基部葉叢；成熟株才顯示三根完整彎曲花莖與花穗。
- 保留既有花卉資料、種植數值、存檔格式與其他花種外觀，不引入外部 3D 套件。
