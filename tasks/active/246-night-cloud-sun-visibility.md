# 任務246：修正夜間雲朵過亮與太陽不可見

## 問題回報
1. 夜晚的雲朵仍然明亮，與夜間天空不協調。
2. 遊戲中看不到新增的太陽，手機窄畫面尤其需要檢查。

## 修正範圍
- 大幅降低夜間雲朵的頂點顏色亮度，並讓夜間雲朵透明度隨日照一起降低。
- 縮小太陽沿天空的水平移動幅度，避免太陽在初始手機鏡頭中落到視野外。
- 保留白天太陽沿日照週期移動、清晨／黃昏色溫變化，以及雨天隱藏太陽的行為。
- 更新瀏覽器回歸測試，檢查夜間雲朵亮度與太陽路徑參數。

## 驗收條件
- 夜晚雲朵不再呈現明亮白色，僅保留低對比的暗色輪廓。
- 初始桌面與手機鏡頭在白天均可看到太陽。
- 太陽仍會隨日照週期移動，且不因相機平移而跟著移動。
- JavaScript／Playwright 驗收通過；使用者確認實際視覺效果後再視為驗收完成。

## 執行紀錄
- 已將夜間雲朵亮度公式調整為 `0.035 + daylight * 0.965`，並依日照降低雲朵透明度。
- 已將太陽水平角度掃掠縮小至 `(daylightArc - 0.5) * 0.32`，並微調垂直路徑。
- 已更新 `tests/browser-smoke.mjs` 的對應規格斷言。
- 待確認 GitHub Actions 的瀏覽器驗收與 Pages 自動部署結果；尚未取得使用者視覺驗收。
