# 任務202：頭像設定獨立彈出

## 需求
將自訂頭像設定從一般設定介面獨立出來，玩家點擊花園名稱左側的頭像時才彈出設定。

## 範圍
- 頭像顯示仍依現有自動／手動模式運作，保留 11 種花卉素材與既有存檔欄位。
- 頭像設定使用獨立對話框，提供明確關閉按鈕，支援 Escape 與點擊遮罩關閉。
- 不更動花卉選擇與頭像計算規則。

## 驗收條件
- 預設不顯示頭像設定。
- 點擊花園頭像可開啟設定，關閉操作有效。
- 自動／手動切換、11 種花卉選擇及重新載入後的存檔行為正常。
- 桌面與手機對話框可捲動，按鈕可操作。
