# 任務237：WebGL 動態光照與夜間照明

## 問題

目前場景頂點色直接輸出，立體明暗由模型幾何建立時寫死的面色決定，無法隨世界光向及日夜改變；CSS brightness 只造成輕微整體變暗，夜間花園仍過亮。

## 方案

採用方案 A：在 WebGL 幾何上傳階段依每三個頂點計算面法線，新增 normal attribute；由 vertex shader 依世界法線、相機方向與日夜光照 uniform 計算受光顏色。維持原生 WebGL，不新增依賴、不修改 11 個花卉模型檔案。

## 驗收條件

1. 場景光影由法線及方向光計算，不再只依賴固定面色。
2. 旋轉相機時，朝向相機的面保持可見且光影依世界光向一致變化。
3. 日間有明確方向光與環境光；黃昏、黎明可帶暖色；夜間環境光與方向光顯著降低，花園確實變暗但仍可辨識。
4. 雨天可降低直射光並調整色調；不破壞既有雨水、天空、花園互動與無人機效果。
5. 不修改花卉模型原始幾何檔案，不引入第三方依賴。
