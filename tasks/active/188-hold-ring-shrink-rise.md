# 任務188：以透明花草環素材呈現長按動畫

## 需求
使用專案 assets 中的花草環透明圖片，取代程式即時繪製的 SVG 葉片與花朵。整張花草環沿用原有長按動畫：前200ms隱藏，接著0.2秒上升50px並縮小，最高點停留0.2秒，最後0.1秒放大復原。不顯示進度條。

## 素材
- 使用 `assets/花草還.webp`（GitHub 目前實際檔名；檔案格式為 WebP）。
- 以 `src/sky-world.js` 建立裝飾圖片，使用透明背景且不攔截指標事件。
- 顯示尺寸46×46px，讓花草沿圓環貼合，不額外製作放射狀葉片。

## 驗收
- Playwright 確認 PC 與手機按下後200ms前隱藏。
- 確認花草環圖片路徑、尺寸與動畫延遲/時長。
- 確認最高點上移50px，放開手勢回饋與移動取消行為保留。
