# 任務188：花草圓環長按動畫

## 需求
以原本長按圓環動畫為骨架，改成白色圓環，搭配綠色葉片與白色小花裝飾；不顯示進度條。動畫前200ms隱藏，顯示後上升50px並縮小，到達最高點停留0.2秒，最後0.1秒放大回原本尺寸。

## 動畫規格
- 前200ms：圓環隱藏。
- 顯示後0.2秒：圓環上升50px，縮至約72%。
- 最高點停留0.2秒，維持縮小狀態。
- 最後0.1秒：放大至原本尺寸。
- 圓環外徑約38px、內徑約30px；白色描邊，沿圓周點綴綠葉與白色五瓣小花。
- 保留指標移動時取消圓環的行為，且不改變既有長按判斷。

## 驗收
- 確認 SVG 裝飾、白色描邊與 CSS 動畫規格存在。
- 確認 Playwright smoke test 驗證無進度條、圓環尺寸及動畫時序。

## 裝飾微調
- 綠葉增加至8片，沿圓環均勻分布。
- 葉片中心貼合圓環半徑，長軸沿圓周切線排列，縮小葉片尺寸以避免葉片突出圓環外緣。
