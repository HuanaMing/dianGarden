# 任務188重做：完整圓環上升與縮放

## 需求
長按總計500ms。前200ms不顯示圓環；後續顯示完整圓環並上升，途中逐漸縮小；最後100ms停在最高點繼續縮小，500ms結束時恢復原本大小。不要顯示環形進度條或逐段繪製的弧線。

## 實作規格
- 0–200ms：圓環隱藏。
- 200–400ms：完整圓環上升50px，尺寸由100%縮小至55%。
- 400–500ms：圓環停在最高點，繼續縮小至35%。
- 500ms結束瞬間：尺寸恢復至100%。
- 圓環使用原本藍色半透明描邊、外徑38px、內徑30px；不繪製進度、不顯示底環，並保留移動時取消圓環的行為。

## 驗收
- Playwright 驗證圓環前200ms隱藏、動畫延遲200ms、動畫持續300ms、上升50px、縮小與復原。
- 驗證圓環為完整靜態描邊，不使用 stroke-dasharray 進度動畫。
- 部署結果待 GitHub Actions 完成後補記。
