# 任務 267：無人機離開與返回平台的巡航高度

## 目標
更新無人機尋路高度判定，確保無人機離開停靠平台及返回停靠平台時，水平巡航路徑始終高於平台頂面，避免巡航高度低於或穿過平台。

## 範圍
- 修改 `src/sky-world.js` 的巡航高度計算。
- 保留現有尋路路線、避障、工作高度、升降動畫及多台無人機的高度分層。
- 不修改存檔格式、派工邏輯或無關視覺功能。

## 實作規劃
1. 依目前停靠平台的高度計算平台頂面。
2. 巡航高度至少高於平台頂面一段安全距離，並與既有障礙物避讓及多機巡航高度預約規則取較高值。
3. 檢查離開平台、任務完成返航及平台高度變動時的高度計算路徑。
4. 執行可用的語法／自動檢查並檢視差異；未實際執行的瀏覽器視覺驗收須如實記錄。

## 驗收條件
- [ ] 無人機離開平台時，先升至高於平台頂面的巡航高度，再水平移動。
- [ ] 無人機返回平台時，水平巡航高度高於目的平台頂面，抵達平台上方後才下降停靠。
- [ ] 平台高度變動後，新計算的巡航高度仍符合安全距離。
- [ ] 保留既有障礙物避讓與多機巡航高度分層。
- [ ] 已檢查修改差異並如實記錄測試結果。
