# 任務255：追查並修正無人機偶發瞬移（返航路徑變更）

## 問題描述
任務225已修正電量更新造成的路徑重算，但使用者回報無人機仍偶爾瞬移。本任務追查剩餘的路徑／動畫同步問題，優先處理飛行期間停靠平台位置改變的情境。

## 調查發現
- `src/sky-world.js` 的 `setDroneDocks()` 在停靠座標改變時，會更新飛行動畫的 `idlePosition`。
- 若無人機已進入返航階段，現有程式以原始工作目標重新計算 `returnRoute`，但動畫 elapsed 仍沿用舊進度；新路徑因此可能在既有進度下直接跳到另一個位置。
- 若平台在去程／作業期間移動，現有程式更新停靠目標卻未必同步更新返航路徑；返航路徑終點與最後下降階段的停靠座標可能不一致。
- 任務225的既有回歸測試只持續更新電量，沒有覆蓋飛行期間移動停靠平台或返航途中重規劃路徑。

## 修正範圍
- 返航途中若停靠位置改變，從無人機目前位置與高度建立新的返航段，並重新起算該段進度，確保位置連續。
- 去程／作業期間若停靠位置改變，於返航開始前更新返航路徑。
- 保留原有派工、避障、工作完成回呼、電量及存檔行為；不新增外部依賴。
- 為「返航途中移動平台」與「去程期間移動平台」增加瀏覽器回歸覆蓋。

## 驗收條件
- 電量更新不會重設飛行路徑。
- 去程或作業期間平台改位後，返航會前往最新平台位置且不瞬移。
- 返航途中平台改位時，無人機從當前位置平順改道，不因舊 elapsed 套用到新路徑而跳位。
- 單機與多機既有飛行／派工流程維持正常。
- 執行 JavaScript 語法檢查與 GitHub Actions Playwright 桌面／手機回歸測試；另行記錄尚未完成的實機視覺驗收。
