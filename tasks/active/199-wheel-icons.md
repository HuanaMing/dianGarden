# 任務199：移除輪盤文字並放大像素圖示

## 需求
1. 移除快捷輪盤所有選項的可見文字，包含無人機、農地管理、設定、圖鑑、收合介面及旋轉。
2. 將輪盤中的四種 PNG 像素圖示放大為原本尺寸的 2 倍；重作時以目前圖示尺寸為基準縮小至 70%；桌面版由 50×50px 調整為 35×35px，手機版由 46×46px 調整為約 32×32px。
3. 保留按鈕的 aria-label、role、data-wheel-action 及既有互動；頂部資訊列不受影響。
4. 不更動花草環背景、輪盤位置與尺寸。
5. 四種 PNG 圖示各自獨立控制位置，並沿各自按鈕的徑向向輪盤外側移動；在原位置基礎上再向外移動 15px；桌面版總外移量 43px、手機版總外移量 42px。每個圖示有獨立的水平微調量與外移距離，避免共用同一個垂直位移造成所有圖示朝畫面上方移動。

## 驗收條件
- 六個輪盤選項皆不顯示文字標籤。
- 四種 PNG 圖示桌面版為 35×35px、手機版為約 32×32px（以本次修改前尺寸的 70% 為目標）。
- 四個 PNG 圖示分別沿輪盤半徑向外移動，且可各自調整水平微調量與外移距離。
- 圖示保持正向，不隨輪盤扇形旋轉；輪盤按鈕仍保留無障礙名稱與原有操作識別。
- 頂部按鈕文字／素材及其他 UI 不受影響。

## 執行結果
- 已移除輪盤六個選項的可見文字標籤；按鈕 aria-label 與操作屬性保留。
- 四種 PNG 圖示目前尺寸為桌面版 35px、手機版 32px。
- 已在 `src/styles.css` 為無人機、農地管理、設定、圖鑑分別建立 `--icon-x` 與 `--icon-outward` 參數；目前桌面版總外移 43px、手機版總外移 42px。
- 已在 `src/index.html` 為四個 PNG 圖示加入獨立定位所需的 `wheel-icon-upright` 標記，讓圖示沿各自按鈕的徑向外移，同時維持圖示正向。
- 保留目前輪盤扇形裁切區設定；尚未執行瀏覽器視覺驗收，需確認圖示完整顯示及與花草環的距離。
