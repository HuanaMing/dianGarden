# 任務199：移除輪盤文字並放大像素圖示

## 需求
1. 移除快捷輪盤所有選項的可見文字，包含無人機、農地管理、設定、圖鑑、收合介面及旋轉。
2. 將輪盤中的四種 PNG 像素圖示放大為原本尺寸的 2 倍；桌面版由 25×25px 調整為 50×50px，手機版由 23×23px 調整為 46×46px。
3. 保留按鈕的 aria-label、role、data-wheel-action 及既有互動；頂部資訊列不受影響。
4. 不更動花草環背景、輪盤位置與尺寸。

## 驗收條件
- 六個輪盤選項皆不顯示文字標籤。
- 四種 PNG 圖示桌面版與手機版尺寸皆為原本 2 倍。
- 輪盤按鈕仍保留無障礙名稱與原有操作識別。
- 頂部按鈕文字／素材及其他 UI 不受影響。

## 執行結果
- 已移除輪盤六個選項的可見文字標籤；按鈕 aria-label 與操作屬性保留。
- 四種 PNG 圖示尺寸由桌面版 25px、手機版 23px，分別調整為 50px、46px。
- 尚未執行瀏覽器視覺驗收。
