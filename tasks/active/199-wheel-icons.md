# 任務199：快捷輪盤圖示尺寸、定位與辨識度

## 需求

1. 移除快捷輪盤六個選項的可見文字標籤；保留必要的圖示及輔助技術名稱。
2. 四種 PNG 圖示依重作要求縮小為本次修改前尺寸的約 70%：桌面版 35×35px、手機版 32×32px。
3. 四種 PNG 圖示沿各自按鈕的徑向向輪盤外側定位，桌面版中心徑向距離約 104px，手機版約 100px；四個操作仍各自可設定角度及位置。
4. 解決圖示被扇形按鈕的 `clip-path` 裁切問題。圖示須放在輪盤容器內、按鈕裁切區外的獨立覆蓋層，且不攔截指標事件。
5. 圖示保持正向，不隨扇形旋轉；新增白色外框與輕微深色陰影，提高圖示和花草環的對比。
6. 保留六個按鈕的 `role`、`aria-label`、`data-wheel-action` 及既有操作；頂部資訊列、花草環素材、輪盤位置與尺寸不應受影響。
7. 將必要的驗收條件加入 Playwright 瀏覽器 smoke test，並保存桌面及手機輪盤截圖。

## 驗收條件

- 六個輪盤操作完整、順序正確且不顯示文字標籤；無障礙名稱仍存在。
- 四張 PNG 圖示都成功載入，桌面為 35×35px、手機為 32×32px。
- 四張圖示位於不受按鈕扇形 `clip-path` 影響的覆蓋層；徑向位置符合桌面約 104px、手機約 100px。
- 圖示維持正向，白色外框濾鏡生效；覆蓋層不攔截指標事件。
- 輪盤選取、旋轉、收合及其他既有操作通過回歸測試。
- 桌面與手機截圖可用於檢查圖示是否完整、白框是否清楚、圖示是否與花草環糊在一起。
- 瀏覽器測試及必要部署狀態確認後，才將任務歸檔為完成。

## 實作紀錄

- `src/index.html`：四張 PNG 圖示改放在獨立的 `.wheel-icon-overlay` 元素，保留四個原操作按鈕與其無障礙屬性。
- `src/sky-world.js`：以 `data-wheel-icon` 對應操作順序，將圖示覆蓋層同步設定為每 60 度一個角度。
- `src/styles.css`：桌面 35px、手機 32px；桌面徑向中心距離約 104px、手機約 100px；加上四方向白色 drop-shadow 外框與輕微深色陰影。
- `tests/browser-smoke.mjs`：新增輪盤操作名稱、文字標籤、圖示載入、尺寸、裁切層、白框濾鏡及手機徑向位置檢查。
- `.github/workflows/browser-smoke.yml`：新增可重現的 Playwright Chromium 驗收工作流程，並上傳截圖 artifact。
