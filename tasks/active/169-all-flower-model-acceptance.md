# 任務 169：全花種模型總驗收自動化

## 目標
把花卉圖鑑的瀏覽器自動驗收擴充為十一種花卉逐一巡覽與截圖，讓每次模型修改後都能快速檢查所有花種是否能載入、切換與繪製，減少專屬模型改動造成其他花種退化的風險。

## 範圍
- 擴充 `tests/browser-smoke.mjs`，依序選取花種索引 0–10，確認選取狀態與 WebGL 畫布可用，並為每種花卉保存獨立截圖。
- 保留首頁桌面／手機截圖與既有圖鑑資料數量檢查。
- 保留瀏覽器錯誤監聽，若出現頁面例外或 console error，驗收應失敗。
- 截圖只作為人工視覺驗收證據；不得把「成功產生截圖」等同於模型外觀已自動判定正確。

## 驗收條件
- [x] 十一種花卉皆可在圖鑑中逐一選取（已加入自動化步驟，等待 CI 實際結果）。
- [x] 每種花卉皆產生可供檢視的模型畫布截圖（已加入自動化步驟，等待 CI 實際結果）。
- [ ] 花園首頁桌面與手機截圖仍正常產生。
- [ ] 圖鑑花種數量、WebGL 畫布與瀏覽器錯誤檢查仍有效。
- [ ] JavaScript 語法檢查與 GitHub Actions 瀏覽器驗收通過。
- [ ] 將執行結果、截圖位置與限制記錄於任務文件。
