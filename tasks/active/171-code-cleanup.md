# 任務 171：清理反覆修改遺留的無用程式碼

## 目標
逐段辨識並移除確定無用的程式碼，降低維護成本；每次移除一個獨立區塊後，立即執行對應檢查，確認沒有引入功能退化，再進行下一段。

## 原則
- 不以「看起來沒用」作為刪除依據；先查詢宣告、引用、事件綁定、跨模組介面與動態呼叫。
- 每一段刪除都要獨立提交，並在下一段修改前執行可用的靜態檢查及 Playwright 瀏覽器驗收。
- 若檢查失敗，先還原或修正該段，不得繼續累積未驗證變更。
- 不改變遊戲規則、模型外觀、操作流程、存檔格式或相容性。
- 不刪除僅因目前測試未覆蓋就看似無用的程式碼。
- 記錄每段刪除內容、判定依據、驗證命令與結果。

## 驗收條件
- 每段清理均有對應的檢查結果。
- 遊戲首頁、WebGL 場景、花卉圖鑑及十一種花卉模型的瀏覽器驗收通過。
- 無法證明無用或缺少適當驗證的程式碼保留不動，並列為待確認。
- 更新任務紀錄與專案狀態，明確列出實際刪除及尚未清理項目。

## 進度
- 開始前盤點專案規範、狀態、主要模組與現有 Playwright 驗收流程。
- 尚未刪除任何程式碼；先建立基準並逐段確認候選項目。
