# 任務239：天空元素世界座標與日月東升西落

## 需求
轉動相機時，天空元素必須因世界座標與相機視角產生視差，不再固定在畫面上。雲使用世界座標中的半透明低面數色塊並緩慢飄動。太陽與月亮暫不繪製幾何模型，待使用者提供 PNG 貼圖素材後再另行接入。

### 重做要求（2026-10-26）
1. 移除太陽與月亮的幾何模型及相關繪製；目前不使用替代模型或臨時貼圖，等待使用者自行提供 PNG 素材。
2. 雲層移到一般相機縮放距離以外的遠景高空，避免雲與空島形成不自然的前後遮擋關係。
3. 雲朵尺寸明顯加大，並適度提高不透明度以確保轉動相機時有足夠可見度。
4. 保留世界座標視差、緩慢飄動、晴雨配色及原生 WebGL，不改變相機操作、存檔格式或遊戲玩法。

## 範圍
- 只修改 3D 場景天空呈現及必要的環境狀態傳遞；沿用原生 WebGL，不新增依賴。
- 雲使用世界座標、共用相機投影／視圖矩陣，旋轉相機時產生自然視差。
- 雲層放置於一般相機縮放範圍之外的遠景高空，尺寸加大、透明度適度提高，避免在主要空島前方形成不自然遮擋。
- 雲沿世界座標緩慢移動，並保留晴雨配色。
- 太陽與月亮的幾何模型暫時移除，待使用者提供 PNG 貼圖後再實作。
- 不變更遊戲經濟、存檔格式、相機手勢及既有日夜／天氣邏輯。

## 驗收條件
1. 旋轉相機時，雲層相對地景移動，呈現世界座標視差。
2. 雲為半透明低面數色塊，位於遠離主要空島的高空背景，尺寸足夠大且容易辨識。
3. 雲持續緩慢飄動，不突然跳位；晴雨配色合理。
4. 太陽與月亮的幾何模型已移除，不會在場景中繪製。
5. 桌面與手機瀏覽器回歸測試通過；不新增依賴、不更動存檔格式。
