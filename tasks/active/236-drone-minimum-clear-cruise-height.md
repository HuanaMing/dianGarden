# 任務236：無人機最低安全巡航高度

## 需求

無人機每次前往目標地塊前，先依自身至目標的水平路徑計算最低可用巡航高度：路徑不得被地塊、草地或植物阻擋，且不得與其他無人機已預約的巡航高度衝突。先垂直上升至計算出的高度，再水平移動；水平移動結束後釋放自己的巡航高度，下一次前往其他地塊時重新計算。

## 範圍

- 修改 `src/sky-world.js` 的無人機動畫與路徑高度安排。
- 不改變遊戲存檔格式、派工邏輯、工作目標及返航政策。
- 其他無人機的巡航高度只在該機水平飛行期間視為已預約；完成水平移動後即釋放。

## 驗收條件

1. 每次新任務出發時重新計算巡航高度，而非固定依無人機索引分配高度。
2. 若直線水平路徑無障礙，使用最低可用巡航高度；若有地塊、草地或植物阻擋，巡航高度高於路徑上障礙物頂端並保留安全間距。
3. 不同無人機同時水平巡航時，不會預約相同高度。
4. 無人機先原地垂直上升，再開始水平移動；水平段結束後清除高度預約。
5. 既有工作、返航及連續同地塊工作行為不應因本次修改而回歸失效。
