# 任務 157：無人機工作動畫結束即交接

## 執行結果
- 工作動畫到達目標工作結束點時立即提交狀態、釋放 `activeJobs` 並重新派工，不等待返航動畫完成。
- 返航中的無人機可在空出工作槽後接取新工作；若無新工作，原返航動畫繼續至停靠坪。
- 同一無人機優先接取上一項工作的同一地塊；同地塊銜接會從目前位置開始，不升回巡航高度。
- 其他地塊工作從返航當下的位置啟動新航線；既有電量門檻、同地塊防重複及擴建互斥仍保留。
