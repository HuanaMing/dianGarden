# 任務197：長按快捷輪盤重做與介面互斥

## 最新需求
1. 滑到輪盤「旋轉」方向時，立即收起輪盤並進入拖曳旋轉，不等待放開。
2. 手指／滑鼠放開或取消時，立即退出旋轉。
3. 移除各選項的可見 container／底板；滑到某個方向時，只放大該方向對應的 60 度花草環區段。
4. 花草環素材可見度為 100%。
5. 保留六個選項：無人機、農地管理、設定、圖鑑、收合／展開介面、旋轉；無人機／農地管理／設定面板互斥。

## 驗收條件
- 長按空白場景約 500ms 顯示輪盤。
- 滑到旋轉區段的同一個 pointermove 事件即收起輪盤並開始旋轉；放開／pointercancel 後退出旋轉。
- 選項不顯示底板與邊框，中心透明；選取狀態會放大對應花草環區段。
- 花草環使用 assets/wreath.webp，opacity 100%、visibility visible。
- 地塊長按移動、雙指縮放維持原操作。
- 無人機、農地管理、設定三個面板互斥。
- 回歸測試涵蓋選項、素材、無底板／透明中心、即時進入旋轉與放開退出。
