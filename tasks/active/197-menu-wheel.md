# 任務197：長按快捷輪盤重做與介面互斥

## 需求
1. 長按空白場景後顯示快捷輪盤，新增「旋轉」選項，取代原本以長按空地直接啟動旋轉的操作。
2. 輪盤不顯示中央實心圓；六個選項各使用 60 度環弧形 container。
3. 沿用專案 assets/wreath.webp 花草環圖案作為輪盤裝飾。
4. 輪盤保留無人機、農地管理、設定、圖鑑、收合／展開介面，並新增旋轉。
5. 開啟無人機、農地管理、設定其中一個介面時，自動關閉其餘兩個介面。

## 驗收條件
- 長按空白場景約 500ms 後顯示輪盤，滑動選擇項目並放開執行。
- 六個選項按 60 度間隔環形排列；中心保持透明，不繪製實心圓。
- 輪盤顯示 assets/wreath.webp 花草環素材。
- 選擇「旋轉」切換旋轉模式；啟用後拖曳空白場景旋轉視角，關閉後回到平移。
- 地塊長按移動、雙指縮放不受影響。
- 無人機、農地管理、設定三個面板互斥，按鈕狀態與 aria-expanded 同步。
- 回歸測試涵蓋六個選項、花草環素材、旋轉模式與面板互斥。

## 執行結果
- 已修改 src/index.html、src/styles.css、src/sky-world.js、tests/browser-smoke.mjs 與 docs/architecture.md。
- 輪盤改為六個 60 度環弧選項，移除中央實心圓並加入 assets/wreath.webp。
- 新增旋轉模式切換，長按空地只負責開啟輪盤；旋轉由輪盤選項明確啟用／停用。
- 已補上自動回歸測試；目前尚待 GitHub Actions 結果與實際瀏覽器驗收。
