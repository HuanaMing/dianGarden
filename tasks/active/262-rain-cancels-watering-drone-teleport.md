# 任務262：修正雨後澆水任務取消造成的無人機瞬移

## 狀態
進行中；由使用者實際遊玩回報的新重現情境觸發。

## 重現條件
1. 在植物尚未濕潤時派發澆水任務。
2. 無人機已領取任務並開始飛行／澆水動畫。
3. 下雨使所有植物被雨水標記為濕潤，已派發的澆水任務因此失去效用。
4. 已領取澆水任務的無人機出現瞬移。

## 目標
釐清並修正雨水更新植物狀態、澆水工作提交失敗／取消、工作佇列與動畫位置所有權之間的競態。取消工作不能直接重設無人機世界座標，也不能讓遊戲工作狀態與動畫狀態失去同步。

## 初步程式線索
- `src/game.js` 的 `applyRainMoisture()` 會將所有植物標記為 `watered = true`、`waterSource = 'rain'`，並更新澆水加速時間。
- `completeJob()` 在提交澆水結果時，如果下雨或植物已濕潤，會回傳 `false`。
- `processJobQueue()` 在派發澆水工作前也會重新檢查植物狀態；`cancelMatureWaterJobs()` 會標記部分 active 水任務取消，但目前沒有顯式要求 `src/sky-world.js` 停止或安全返航對應動畫。
- `src/sky-world.js` 的位置由 `droneStates[index].animation` 擁有；`setDroneDocks()` 在動畫為 null 時會同步位置到停靠點。必須透過動態測試確認瞬移實際發生在哪個交接點，不能只依靜態推測。
- 最新狀態機測試 run #787 另有 `tests/browser-smoke.mjs` 語法錯誤，修復時需確保新增測試不受該問題影響，並先恢復測試腳本可解析。

## 範圍
- 建立可重現的 Playwright 測試：在無人機正在執行澆水工作時切換為雨天／套用雨水濕潤，量測連續幀位置，確認沒有超門檻跳位。
- 查明任務被取消或結果不再需要時，工作生命週期與動畫生命週期如何結束。
- 以最小變更確保取消中的無人機保留目前位置控制權，並安全完成／中止動畫，不重設到停靠平台。
- 加入回歸驗收：雨中所有植物濕潤、排隊澆水取消、已領取澆水任務取消、播種接澆水既有交接、八機平台移動。
- 更新任務紀錄與狀態 JSON，明確記錄實際執行的測試結果。

## 驗收條件
- 雨水令澆水任務失效時，已領取任務的無人機不會瞬移。
- 取消後不會重複提交澆水結果，也不會留下永久 active job 或卡住的動畫。
- 無效澆水工作不阻擋其他有效工作；必要時從目前位置平順返航或接續有效任務。
- Playwright 瀏覽器測試可重複執行且通過，並且既有工作交接及多機回歸沒有退化。
