# 任務 150：濕潤水滴固定在植物周遭

## 目標
調整植物濕潤效果的水滴位置，水滴不再持續向上飄移，而是固定分布在植株周遭。

## 範圍
- 檢查 `src/sky-world.js` 中植物澆水／雨後濕潤的水滴特效。
- 移除水滴隨時間向上位移的動畫；保留合理的環繞分布與視覺辨識度。
- 濕潤狀態結束時，水滴特效應停止顯示。
- 不改變澆水規則、成長加速時間、天氣結算或存檔格式。

## 驗收條件
- 水滴不會持續向上漂離植物。
- 水滴保持在植物根部至植株周遭的合理範圍。
- 濕潤狀態結束後不殘留水滴。
- 其他場景粒子與植物模型不受影響。

## 驗證
- 檢查特效更新函式與濕潤期限判斷。
- 執行可用的 JavaScript 語法檢查；瀏覽器視覺驗收若未執行，需明確註記。
