# 任務 277：採收後返航限制與透明箱花頭展示

## 目標
1. 無人機完成花朵採收後，必須先返回停靠平台，才可再次接取花朵採收任務。
2. 限制只套用於 `harvest` 任務，不阻擋播種、澆水、擴建等其他工作。
3. 採收完成後，將該次採收的花頭顯示於無人機機身透明箱內，持續懸浮並緩慢繞 Y 軸旋轉。
4. 花頭展示持續到無人機實際完成返航；若返航途中接續其他工作，花頭仍保留，直到後續返航完成。
5. 保留既有花朵採收、金幣入帳、自動播種與其他任務的行為。

## 修改範圍
- `src/game.js`：採收返航資格鎖定與解除。
- `src/sky-world.js`：保存採收花頭資料、繪製透明箱內花頭與旋轉動畫。
- `tests/browser-smoke.mjs`：加入回歸契約檢查。
- 任務／專案狀態紀錄。
- 目前先在 `feature/drone-harvest-display-return` 分支修改；不部署、不觸發正式發布。

## 驗收條件
- 採收完成後，該機的再次採收派工會被阻擋，直到返航完成回呼執行。
- 被鎖定的無人機仍可接取非採收工作。
- 其他工作若延續出勤，採收花頭仍留在透明箱內；真正返航完成後清除。
- 花頭使用該次採收的花種與自訂花色資料，不因農地清空或重新 render 而消失。
- 花頭在透明箱內有輕微上下懸浮，並持續繞 Y 軸緩慢旋轉。
- 加入靜態回歸檢查；可用的語法與瀏覽器測試需實際執行並記錄結果。
- 不修改存檔格式，不引入新套件，不部署。
