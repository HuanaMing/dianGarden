# 任務 266：無人機植物玻璃花窗振翅模型

## 目標
將現有無人機改造為花明摸魚花園專屬的植物工藝風格模型，並加入規律的上下振翅動畫。

## 已確認設計
- 機身：保留木質立方體與既有電量指示燈。
- 翅膀：左右各一片方形木框透明植物玻璃花窗；玻璃以透明、淡綠葉片及淡色花卉為主，細木框避免遮擋圖案。
- 安裝：翅膀由機身上半部、略高於中心的位置向左右伸出。
- 連接：以藤蔓纏繞木質肩架，銜接機身與翅膀，葉片點綴但不遮蔽花窗。
- 動態：左右翅膀同步、規律機械式上下拍動，每秒約 2 次完整往返（2 Hz）。翅膀面朝上下，運動方向須如鳥翼上下拍動，不是左右翻轉或水平旋轉。
- 視覺參考：使用者確認的任務 266 概念圖；以實際遊戲中 WebGL 幾何可讀性為準，不要求複製概念圖的寫實材質。

## 範圍
- 主要修改 `src/sky-world.js` 的無人機幾何及振翅動畫。
- 優先使用現有 WebGL 頂點／顏色／透明度流程，不新增外部套件、圖片資產或建置步驟。
- 保留現有機身、電量燈、光暈、朝向、懸停、移動、派遣、返航、停靠及選取行為。
- 不修改存檔格式、派工邏輯或無關場景。

## 實作規劃
1. 讀取並確認 `addDrone` 幾何建立、頂點旋轉／更新及每幀繪製的完整呼叫鏈。
2. 建立簡潔的方形花窗翼：細木框、透明淡綠玻璃區塊、少量葉片與淡色花朵圖樣；以現有頂點顏色及透明度表現。
3. 以機身上方左右肩架與藤蔓幾何連接兩片翅膀。
4. 將翅膀幾何與機身幾何分離，讓每片翅膀可繞各自根部沿鳥翼上下方向旋轉。
5. 使用時間驅動的週期函數，左右同步，頻率 2 Hz；振幅採保守值以避免穿入機身或造成幾何翻面。
6. 執行語法檢查、既有可用測試及差異檢查；若無瀏覽器可用，明確記錄視覺驗收限制。

## 驗收條件
- [ ] 機身仍為木質立方體，既有電量指示燈與光暈正常。
- [ ] 左右翅膀是方形、細木框、透明植物花窗，具有淡綠葉片與淡色花朵。
- [ ] 翅膀由機身上半部略高於中心的位置伸出，藤蔓肩架連接自然。
- [ ] 翅膀的主平面朝向上下拍動方向，動作像鳥翼上下拍動，不是平面左右擺或水平翻轉。
- [ ] 左右翅膀同步，每秒約 2 次完整上下往返。
- [ ] 飛行轉向、升降、派遣、返航、停靠、選取、電量顯示與光暈沒有被破壞。
- [ ] 完成語法／可用自動測試；尚未能實際確認的視覺項目須清楚標示。
