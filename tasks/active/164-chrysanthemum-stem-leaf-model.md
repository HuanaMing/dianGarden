# 任務 164：菊花專屬莖葉模型

目標：為菊花（花種索引 6）建立專屬莖葉幾何，保留既有花頭、花色、遊戲數值及存檔格式。

建模方向：成熟株採直立漸細草本主莖並與花頭底部接合；葉片沿主莖互生，具有羽狀裂葉與粗鋸齒感邊緣、低對比葉脈；幼苗只顯示縮小基部葉叢；花瓣呈細長橢圓舌狀，中央飽滿、末端為圓鈍花瓣帽，不可形成針尖；花頭需有清楚的上下層次與拱起輪廓，避免側面過扁；成熟花頭不追加舊版通用側葉。
