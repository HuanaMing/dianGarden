# 任務192重做：草地斜坡側面跟隨頂面變形

## 需求
草地頂面已經依相鄰地塊產生斜坡，但地塊周圍四側仍使用未跟隨頂面角點的側面幾何，導致頂面與側面看起來像兩個不同形狀。修正側面網格，使四周側面上緣與草地頂面使用相同角點高度，讓側面隨坡面一起變形。

## 實作
- 保留四向鄰居判定：只連接正交相鄰一格，且高度差不超過 0.5；不採用對角線。
- 由相鄰兩側的邊緣高度推導單一共用角點高度。
- 頂面三角面、四周側面上緣及表面高度取樣共用同一組角點，避免側面仍維持水平方形邊框。
- 保留地塊厚度、底面及既有草地材質。

## 驗收條件
- 四周側面頂端與頂面角點使用完全相同的高度值。
- 四邊高度差 -0.5、0、+0.5 的 81 種排列均能生成有效角點高度。
- 對角線、距離超過一格及高度差超過 0.5 的鄰居仍不連接。
- JavaScript 語法與 GitHub Actions Playwright 瀏覽器測試通過。
- 若未人工檢查截圖，需明確記錄視覺驗收限制。
