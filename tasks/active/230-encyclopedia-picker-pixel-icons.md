# 任務230：圖鑑選花標題加入收合／展開像素圖

## 需求
加強圖鑑手機版「選擇花種」標題的上拉／下拉提示，在標題最右側使用既有像素圖：
- 收合狀態使用 `assets/btn/展開.png`，提示可以向上展開選花面板。
- 展開狀態使用 `assets/btn/收合.png`，提示可以下拉收回。
- 圖示需隨面板狀態切換，並保留目前點擊與拖曳手勢。

## 範圍
- `src/encyclopedia.html`
- `src/flower-encyclopedia.js`
- `src/styles.css`
- `tests/browser-smoke.mjs`

## 設計原則
- 使用既有 assets，不另外製作或替換圖檔。
- 圖示靠標題最右側，尺寸適合手機觸控介面；不得擠壓「選擇花種」文字。
- 提供合適的替代文字或 aria 狀態；純裝飾圖示避免重複朗讀。
- 桌面版既有版面不受影響；若提示圖只在手機顯示，需明確以媒體查詢控制。

## 驗收條件
- 手機收合狀態顯示 `assets/btn/展開.png`；上拉展開後顯示 `assets/btn/收合.png`。
- 下拉或點擊收回後圖示正確切回。
- 上拉、下拉、點擊、選擇花種後自動收回等既有行為均正常。
- 兩張素材在部署路徑下可載入，且桌面排版沒有回歸問題。
- 加入 Playwright 檢查圖示來源、狀態切換及手機／桌面顯示行為。

## 依賴
無，可獨立執行。
