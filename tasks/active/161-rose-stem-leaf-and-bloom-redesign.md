# 任務 161：重做玫瑰專屬莖葉與成熟花頭模型

## 目標
依據 `docs/flower-background.md` 的玫瑰株型資料，建立符合灌木型玫瑰辨識特徵的專屬莖葉模型，並完整重做目前不令人滿意的玫瑰成熟花頭幾何。

## 背景資料與建模方向
- 玫瑰以灌木型作為遊戲建模參考：枝條較硬挺、略有斜向分枝，帶刺可視需要簡化。
- 葉片為互生羽狀複葉，由多枚鋸齒緣小葉沿葉軸成對或近似成對排列；小尺寸模型優先保留複葉輪廓、葉序與深淺綠層次。
- 玫瑰花頭採多層重瓣、寬圓花瓣與中央逐步收緊的旋卷花心；避免現有模型僅像四圈尖角三角面堆疊的規則花環。
- 保留玩家自訂花色、現有花種索引、種子／幼苗／成熟階段流程及舊存檔相容性。

## 修改範圍
- `src/sky-world.js`：新增玫瑰專屬莖葉幾何，整個替換玫瑰成熟花頭幾何。
- `docs/architecture.md`：記錄玫瑰專屬莖葉與新花頭模型。
- `docs/desicions.md`：記錄造型設計決策。
- `state/current-task.json`、`state/project.json`、`logs/task-history.md`：同步狀態及工作紀錄。

## 驗收條件
- [ ] 玫瑰使用專屬枝條及複葉模型，不再沿用其他花種的通用莖葉。
- [ ] 成熟花頭已移除舊版幾何並以新的多層重瓣花瓣網格取代。
- [ ] 花瓣呈現有厚薄感的彎曲面、層間錯位與逐步收緊的中心旋卷。
- [ ] 花瓣顏色沿用花種預設色及玩家自訂色。
- [ ] 不改動花種索引、遊戲數值、存檔格式或其他花種模型。
- [ ] JavaScript 語法檢查及靜態結構檢查通過。
- [ ] 在瀏覽器檢查花園及圖鑑中的玫瑰正面、側面與斜上方效果。
