# 任務 278：連續開墾與擴建佇列持久化

## 需求
1. 玩家選擇開墾高度與地塊類型後，啟用連續開墾並自動切換 2D 俯視。
2. 按住拖曳可規劃連續網格路徑，顯示路徑預覽；可隨時返回 3D。
3. 已占用、碰撞或不符合堆疊規則的位置自動略過。
4. 自動地塊與手動地塊都由無人機建造。
5. 同一段路徑在待辦清單合併顯示，仍保留每格獨立工作，並可取消尚未開始的剩餘格數。
6. 單格與連續開墾都屬最高優先級；不打斷已開始的工作。
7. 擴建待辦立即儲存，重啟後可恢復繼續；舊存檔仍可讀取。
8. 不部署。

## 修改範圍
- `src/index.html`、`src/styles.css`：高度／地塊類型控制、連續開墾按鈕、3D 返回入口及路徑預覽樣式。
- `src/sky-world.js`：相機模式 API、2D 拖曳網格路徑與預覽。
- `src/game.js`：路徑逐格驗證、無效位置略過、手動地塊由無人機建造、擴建最高優先、合併待辦顯示、存檔／還原。
- `tests/browser-smoke.mjs`：加入靜態回歸契約。
- `README.md`、`docs/architecture.md`、`docs/desicions.md`、本任務文件及工作歷史。

## 驗收條件
- 開啟連續開墾後切到 2D，顯示拖曳路徑預覽，放開後產生有效的逐格擴建工作。
- 3D 視角可在連續開墾期間切換，模式不必關閉。
- 無效格不會建立工作；有效格由無人機依序建造，手動地塊也一樣。
- 同一路徑合併顯示，取消只移除該組尚未開始的工作。
- 擴建工作優先於作物工作，已開始的動畫不會被中斷。
- 立即儲存的待辦可在重新載入後還原；已建成的地塊不會被重複建立。
- 舊存檔未含 `pendingPlotExpansions` 時仍可載入。
- 靜態語法及回歸檢查通過；瀏覽器驗收需實際執行並記錄。
