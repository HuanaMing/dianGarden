# 任務 175：收合頂部控制列與農地視覺整合

> 狀態：執行中（2026-10-23）

## 目標
統一收合介面時的頂部控制列、三個主要控制按鈕的彈出面板、農地管理版面，以及手動農地的 3D 外觀，讓介面更像同一組自然延伸的控制元件，並讓手動農地能一眼辨識但不破壞場景協調感。

## 需求
1. 介面收合時，左上角留下的三個按鈕保留白色容器。容器為圓角矩形，並與畫面上緣平滑連接。
2. 農地管理面板移到右上角顯示。
3. 收合介面時，農地管理按鈕必須一起隱藏；展開介面後恢復顯示。
4. 農地管理、無人機、設定三個按鈕開啟的面板，都要與觸發按鈕平滑銜接，視覺上像按鈕本身向外延伸。
5. 農地管理內的農地項目採每排五塊排列；購買按鈕區寬度精準對齊第五塊農地項目的右緣。
6. 手動農地在 3D 建模上要與自動農地有明顯但克制的視覺差異，不可突兀或破壞場景協調性。

## 範圍
主要修改 src/styles.css、src/index.html、src/game.js、src/sky-world.js；不引入外部套件、不改存檔格式與遊戲規則，並維持手機版可操作性。

## 驗收條件
- 收合後三個保留按鈕位於與畫面上緣連續的白色圓角容器內；農地管理按鈕隱藏。
- 農地管理面板位於右上角，收合／展開行為正確。
- 農地管理、無人機、設定面板均與觸發按鈕自然銜接，沒有突兀縫隙、錯位或遮擋。
- 桌面版農地清單每排五塊，購買區右緣對齊第五塊農地右緣；手機版不水平溢出。
- 手動農地與自動農地在一般視角下可辨識，但外觀差異低調，且不影響選取、拖曳、種植、成熟、收成與效能。
- 不破壞無人機、設定、介面收合、農地購買、選取及本機存檔。

- 接續調整介面定位與模型資料路徑，再進行語法及瀏覽器驗收。
