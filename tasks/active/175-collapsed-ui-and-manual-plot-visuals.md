# 任務 175：收合頂部控制列與農地視覺整合

> 狀態：執行中（2026-10-23）

## 目標
統一收合介面時的頂部控制列、三個主要控制按鈕的彈出面板、農地管理版面，以及手動農地的 3D 外觀，讓介面更像同一組自然延伸的控制元件，並讓手動農地能一眼辨識但不破壞場景協調感。

## 需求與驗收
1. 收合介面時，設定、花卉圖鑑與展開按鈕保留在左上角白色圓角容器中，容器上緣與畫面連接；農地管理及無人機按鈕隱藏。
2. 農地管理面板移至右上角，且收合時關閉農地管理、設定與無人機面板，避免重新展開時殘留彈窗。
3. 農地管理、無人機、設定面板與頂部控制列自然銜接，面板上緣使用較小圓角與短距離進場動畫，減少懸浮感。
4. 農地清單桌面版每排五塊，購買按鈕區寬度與清單右緣一致；手機版維持五欄但依容器寬度壓縮，不能水平溢出。
5. 手動農地在 3D 模型以低對比鼠尾草綠窄邊框辨識；不更改存檔格式、遊戲規則或花卉幾何。
6. 不破壞無人機、設定、收合、購買、選取、拖曳與本機存檔。

## 執行紀錄（2026-10-23）
- 已盤點 DOM 與樣式：頂部按鈕位於 .topbar-actions；收合時原本仍靠右，農地管理按鈕未獨立隱藏；農地管理面板原先定位左下角，清單採彈性換行。
- src/styles.css：收合後控制列移到左上角，保留白色圓角容器並隱藏農地管理／無人機按鈕；農地管理、無人機與設定面板調整至頂部控制列下方；農地清單改為五欄網格，購買區使用相同寬度。
- src/game.js：介面收合時主動關閉農地管理、設定與無人機面板，並同步更新 aria-expanded。
- src/sky-world.js：將地塊的 manual 狀態傳入 WebGL 場景，並為非草地手動農地增加低對比鼠尾草綠窄邊框；沒有改動存檔格式或花卉模型。
