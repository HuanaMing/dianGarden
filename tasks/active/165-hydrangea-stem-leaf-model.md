# 任務 165：繡球花專屬莖葉模型

目標：為繡球花（花種索引 7）建立專屬莖葉幾何，讓植株外觀與球狀花序相配，保留既有花頭、花色、遊戲數值及存檔格式。

建模方向：
- 主莖自然直立並略微漸細，從土面連續延伸至花球底部。
- 葉片採寬卵形至橢圓形，葉尖略尖、葉基收窄，外緣有柔和鋸齒起伏；以低對比中肋表現葉脈。
- 葉片沿莖部成對對生並略有旋轉錯位，使用較長葉柄向外伸展，避免葉片全部朝同一平面。
- 成熟株的上層葉片避開花球主體，避免穿入花球或遮住花序。
- 幼苗只顯示較小、低矮的基部葉片；成熟株才顯示完整主莖及分層葉片。
- 移除繡球花成熟株流程中的舊版通用側葉，避免重複疊加。
