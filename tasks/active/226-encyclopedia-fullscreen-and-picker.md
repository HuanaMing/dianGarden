# 任務226：修正圖鑑全螢幕與手機選花面板

## 需求
1. 修正圖鑑預覽進入全螢幕後花卉模型消失的問題。
2. 手機版「選擇花種」標題可向上拖曳，讓選花面板向上展開並覆蓋部分預覽區，增加花種清單可視空間。
3. 選花面板可向下拖曳收回，恢復原本預覽在上、選花清單在下的排版；保留標題點擊操作與桌面版原有排版。

## 範圍
- `src/flower-encyclopedia.js`：全螢幕狀態、畫布尺寸同步、手機面板手勢。
- `src/styles.css`：手機選花面板展開狀態與層級。
- `tests/browser-smoke.mjs`：全螢幕繪圖與手機上拉／下拉回歸測試。

## 驗收條件
- 進入全螢幕後 WebGL 畫布仍有可視尺寸且模型持續繪製；退出後回復原尺寸。
- 手機版可上拉選花標題，面板向上覆蓋預覽區並提供更多清單空間。
- 下拉面板可恢復原排版；點擊標題仍可切換，桌面版不受影響。
- 執行可用的程式語法檢查及 GitHub Actions Playwright 桌面／手機測試，據實記錄結果。

## 執行紀錄
- 已讀取 `AGENTS.md`、`README.md`、專案狀態與圖鑑相關程式。
- 初步發現全螢幕時畫布尺寸僅依賴每影格讀取 CSS 尺寸，尚無專用全螢幕尺寸同步；手機版現有標題按鈕會直接隱藏整個預覽欄，需調整為可拖曳展開的面板。
