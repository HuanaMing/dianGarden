# 系統架構

## 專案概述

花明摸魚花園是使用原生 HTML、CSS 與 JavaScript 開發的瀏覽器小遊戲，不需要建置工具或伺服器。

## 遊戲程式

- `src/index.html` 定義繁體中文介面與遊戲容器，載入樣式表及腳本。
- `src/styles.css` 負責響應式版面、視覺呈現與互動狀態。
- `src/sky-world.js` 使用原生 WebGL 建立可重複拼接的土地方塊與低多邊形花卉模型，管理視角、相機控制、土地點選及視窗尺寸。`window.skyWorld.setLandCount()` 同步土地數量，`window.skyWorld.setPlots()` 同步花卉種類與種植時間，`window.skyWorld.setSelectedPlot()` 同步選取狀態。
- `src/game.js` 管理金幣、農地、種植、成長、收成及開墾，驗證存檔必要欄位，並以瀏覽器 `localStorage` 保存進度。

空島場景不依賴外部 3D 套件，並以全螢幕 `.world-frame` 作為唯一遊戲操作區。標題、金幣、存檔狀態、農地快捷選單、操作提示及擴建入口都覆蓋在場景框內。玩家可以拖曳畫面旋轉視角、使用 WASD 平移相機、使用滾輪縮放；地塊短按可選取或開啟操作視窗，選取地塊以略大於地塊的黃色外框標示，堆疊時外框會露在上層方塊外側；按住任一地塊超過 500ms 即選取並顯示拖曳方向箭頭，不需先移動指標；拖曳時箭頭跟隨預覽，放開或取消時清除。快捷按鈕可直接開啟操作視窗。若瀏覽器無法建立 WebGL context，快捷按鈕與視窗仍可完成完整遊戲操作。種植、成長狀態、收成與擴建確認共用 `#farm-dialog`；確認擴建後才扣款。`src/sky-world.js` 以原生幾何繪製大地色立方體無人機、機身上方唯一一組雙葉旋翼和低位起落架，並透過動畫方法提供工作效果；額外無人機環繞停靠站待命，多台無人機可同時工作。每影格僅更新無人機與短暫工作特效的動態緩衝區，土地與作物幾何只在遊戲狀態變更時重建；若 WebGL 不可用則直接完成操作。

土地使用存檔中的整數 `x`、`z` 網格座標及以 0.5 為步進的 `y` 高度；舊版缺少座標或高度的存檔會補上預設值；既有堆疊下層地塊載入時會轉為純草地並保留座標。首次短按地塊只選取，選取後短按開啟資訊；長按地塊進入移動模式，按住 500ms 後移動可拖曳；短按地塊可在移動與高度模式間切換。高度模式會顯示上下箭頭，地塊上下拖曳依投影比例以 0.5 個土地單位為步進調整高度，坪台高度仍以一個單位為步進。點選空白處可退出高度模式。地塊及坪台高度範圍為 -8 至 8，存入存檔並同步到場景；花卉、地塊、濕潤特效、無人機待命高度及工作航線會隨其地塊／坪台高度移動；無人機以工作索引指定目標地塊，堆疊時依目標高度飛行，不按水平座標猜測目標。拖曳地塊時場景用游標投影到該地高度平面並以最近整數格顯示預覽；進入拖曳後在地塊上方顯示沿世界 X、Z 軸的雙向箭頭。土地立方體垂直厚度為 0.5 個世界單位；同一水平格的地塊可使用 0.5 高度步進堆疊，物理重疊或坪台穿入立方體時拒絕移動。純草地地塊不能種植；若其相鄰地塊高度不同，草地頂面會按四個角點高度生成兩片三角坡面，三角網不使用中心尖點，淺綠斑塊依三角面插值貼合坡度，植株基準放在坡面中心高度；鄰接草地共用角點高度以銜接相鄰坡面。任何上方有地塊或坪台的下層地塊都必須設定 `grassOnly`，否則禁止切換、移動或調整到該堆疊位置。存檔驗證與場景操作套用相同規則。天空空白處拖曳旋轉相機。

花卉模型依各自的成熟時間切換：先顯示種子，再顯示幼苗，成熟後顯示花朵模型。模型高度以一塊土地的一個世界單位為基準，向日葵最高（0.95）、玫瑰次之（0.62），風信子（0.34）與鈴蘭（0.30）較矮，以表現常見植株的相對尺寸。成熟向日葵的花瓣與中心盤排列在垂直平面，花盤法線朝水平的 +Z 方向；種子及幼苗模型不受此方向調整影響。

目前十一種花卉的遊戲成熟時間均調整為前一版本的三倍（54 至 135 秒；玫瑰為 67.5 秒），作物目錄仍是成熟判斷的單一來源；澆水的短期加速仍套用在各作物成熟時間上。

若存檔無法解析或未通過欄位驗證，遊戲會保留原資料不覆寫，並以新遊戲狀態提供本頁工作階段遊玩。若瀏覽器拒絕儲存或寫入失敗，進度仍留在記憶體中，頁首存檔狀態會提示重新整理可能遺失進度。

目前十一種花卉共用目錄在 `src/flower-catalog.js`，包含花名、花語靈感、遊戲生長時間、模型原始高度、顏色、圖示、種子成本及收成金額。既有索引 0–9 不變；彼岸花追加為索引 10。`src/game.js` 從此目錄讀取玩法數值，`src/sky-world.js` 讀取模型高度並依成長進度繪製低多邊形模型，圖鑑也使用同一目錄呈現資料。

每次播種會在作物地塊存入 0.9–1.1 的 `plantHeight`，幼苗和成熟植株幾何皆以土面為基準套用同一倍率。載入舊存檔時缺少此欄位的作物使用 1.0；空地可為空值。這項視覺倍率不參與生長、收成或花種索引計算。

場景的 2D 模式把相機固定於 `(0, 12, 0)` 並以非平行的 `(0, 0, -1)` up 向量垂直看向原點；模式切換保存並還原 3D 相機姿態。HUD 收合時隱藏 2D／3D 相機切換、花卉圖鑑、重置進度、擴建入口及手機縮放控制；保留收合按鈕與摘要。無人機坪台長按 500ms 後以 `dockPreview` 顯示世界 X、Z 軸方向箭頭，預覽隨坪台位置變化，放開或取消時清除，並沿用既有碰撞驗證。

`src/encyclopedia.html` 以單一 WebGL 場景展示目前選取的一種遊戲內花卉模型，資訊卡按鈕以事件代理支援滑鼠、觸控及鍵盤選取；`aria-pressed` 和即時狀態文字同步指出選取花種。正方形模型區可拖曳旋轉及滾輪縮放。卡片列出花語例子／靈感、遊戲生長時間及原始模型高度，並說明 ±10% 浮動。圖鑑返回入口連至花園頁面，不為個別模型建立額外 WebGL context。

圖鑑版面以視窗高度為界：桌面版左欄展示正方形模型（最大高度約 60vh），模型和變種編輯器同寬且左緣對齊內容起點；右側花種卡片與模型欄保留 30px 間隔，並將其餘寬度交給可獨立捲動的容器。窄螢幕則改為上方模型、下方花種清單，避免整頁超出可視高度。

玩家自訂變種存於 `sky-garden-flower-variants-v1`，每筆以獨立 ID 關聯原始花種索引、名稱和六位色碼，上限 30 筆。地塊只保存變種 ID，原始 `crop` 索引 0–10 不變；手動播種保留原始花種卡片，每張卡片右側的「▷」按鈕會在右側打開該花種的變種面板，逐項顯示設定顏色色塊；自動播種目錄使用原始十一種花。花園和圖鑑只將變種色套用到花頭幾何，變種沿用基礎花種的模型形狀、生長、價格及收成規則。重置進度會一併清除變種資料。

`src/sky-environment.js` 以 `worldTimeMs` 和時間錨點建立可持續的遊戲內時鐘，並集中計算天氣與日夜狀態。日夜循環 16 分鐘，包含 1 分鐘清晨、9 分鐘白天、1 分鐘黃昏及 5 分鐘夜晚；清晨與黃昏的光線值平順過渡。陰雨每 10 分鐘循環一次，最後 2 分鐘為雨；環境濕潤由天氣即時計算，不改寫地塊的 `watered`、澆水加成或生長時間。陰雨期間所有植株及土壤床顯示濕潤，操作視窗提示雨中狀態，自動澆水暫停；天氣轉晴後恢復各地塊原本的澆水狀態。遊戲狀態列與收合摘要顯示時段和天氣；場景依時段平順改變天空背景和亮度，夜間顯示月亮與星點。

`docs/flower-background.md` 彙整現有及候選花卉的花語、園藝成熟時間分級與具名代表株型尺寸，供內容與模型比例設計參考。文件將花語標為文化脈絡而非固定事實，並區分真實園藝年限與遊戲內秒數。

## 任務與專案紀錄

- `tasks/` 以 `inbox`、`active`、`done`、`blocked` 分流 Markdown 任務紀錄。
- `state/project.json` 保存專案總體狀態；`state/current-task.json` 保存目前任務的細節。
- `docs/architecture.md` 與 `docs/desicions.md` 分別記錄架構和決策。
- `logs/task-history.md` 按時間追加已完成任務摘要。

預設待命點 `(0, 1.55)` 設有可選取及拖曳的懸浮停靠平台，與初始農地保持間隔；無人機完成任務後返航到平台上方，閒置旋翼速度較慢。`src/game.js` 以 FIFO 佇列分派播種、收成和澆水工作，為每台已部署且閒置的無人機各派一項不同地塊的工作；同一地塊不會重複派工，擴建則等所有其他工作完成後單獨執行。工作狀態在無人機離開目標時提交；返航完成後才釋放該機並重新派工。場景中的佇列列出等待項目並提供取消按鈕；啟動時才重新檢查作物狀態和金幣，避免等待期間重複扣款或操作失效目標。WebGL 不可用時工作立即提交並釋放機位。

場景佇列面板的自動模式狀態保存在遊戲存檔。啟用後，`planAutomaticJobs()` 會為自動農地的成熟花卉安排收成、為尚未成熟且未澆水的作物安排一次澆水，並為空地從玩家勾選且當前可負擔的種類中隨機挑選播種；手動及草地地塊完全跳過無人機作物工作。透過工作佇列去重，避免重複派遣澆水或收成，不會建立土地或改動 `x`、`z` 座標。關閉後不再排入自動工作，已排入的項目仍可在佇列面板取消。擴建入口的可見文案與無障礙標籤會依目前地塊數動態顯示下一塊地的價格。

每個地塊的 `manual` 布林欄位表示是否為手動農地，`grassOnly` 表示是否完全使用草地表面、不顯示咖啡色種植土壤；兩欄舊存檔缺少時均預設為 `false`。地塊資訊面板使用「自動 → 手動 → 草地」三段循環控制；草地同時設為手動模式，無人機會略過它的播種、澆水和收成，玩家仍可管理已存在的作物。草地地塊不能播種。下方承載平台或其他地塊的地面必須維持 `grassOnly`。切至手動或草地時取消該地塊尚未執行的無人機工作，若正有無人機工作則暫時停用切換直到工作完成；切回自動後依目前全域自動模式狀態恢復管理。


自動播種花種偏好由 `game.autoCropSelection` 保存為作物索引陣列，舊存檔未包含此欄位時預設選擇向日葵。工作規劃只在所選且可負擔的種類中隨機挑選作物；空選取會暫停播種但不影響自動收成。

花園顯示名稱存放在遊戲存檔的 `gardenName` 欄位，由左上角內嵌表單編輯；舊存檔未包含名稱時使用預設品牌名稱。儲存後同步更新場景標題和 `document.title`。

作物有效生長時間由 `growthElapsed()` 統一計算。澆水工作由多機共用工作佇列及每機獨立的 `animateWater()` 飛行狀態執行；每株作物保存一次性的澆水狀態、加速起訖時間與累積生長加成。過期後將加成結算到 `growthBonusMs`，由面板、倒數、收成判斷及 WebGL 作物階段共同使用。舊存檔未含澆水欄位時視為未澆水。

澆水動畫在作物上方停留 2.4 秒，從無人機底部交錯落下六顆水滴，並在植株根部顯示脈動水花；無人機完成目標作業並離開植株時即提交澆水與生長加速狀態；返航完成才釋放活動機位。

`game.hudCollapsed` 保存介面收合偏好。固定 HUD 切換按鈕以 `aria-expanded` 呈現狀態；收合時隱藏頂欄、無人機佇列、農地捷徑及操作提示，保留狀態摘要、擴建入口與直接點擊 3D 土地的操作。

佇列工作以 `automatic` 標記來源。自動播種、澆水與收成成功後只更新狀態，不逐筆顯示 toast；玩家手動工作成功訊息與失敗／失效提示維持可見。

無人機停靠平台預設在 `(0, 1.55)`，平台基座起始高度為 1.30 世界單位，標記最高 1.366；平台不設支柱，呈現懸浮效果。無人機待命於約 1.50 高度，工作航線保持在花卉冠層上方。

停靠平台位置保存於 `game.dockPosition`，包括水平 `(x, z)` 與高度 `y`；舊存檔預設為 `(0, 1.55, 0)`。玩家可點擊平台選取，也可在無人機待命時直接按住平台拖曳，不需先選取；點擊判定包含平台頂面投影及投影中心周圍至少 72 CSS 像素、最大 104 CSS 像素的範圍。無人機工作期間仍可選取平台，但不能拖曳。長按進入平台移動模式，再短按切換高度調整；坪台每增加一個高度單位，平台及待命無人機一同上移一個世界單位。位置吸附整數網格；平台可與土地堆疊，但不能穿入地塊立方體，且位於坪台下方的地塊必須是純草地。移動平台會同步待命無人機與後續返航目標。

無人機待命漂浮以固定待命高度 1.50 為中心，上下位移振幅為 0.012 世界單位，避免逐影格累積高度變化。開始工作時在原地垂直移至工作高度 1.18，再保持此高度水平飛往作物；返航則先水平移動到停靠點上方，再垂直回到待命高度。工作高度高於最高向日葵冠層約 0.175 世界單位。

無人機出勤和返航都使用三段式航線：原地垂直升至專屬巡航高度、沿 A* 格點路徑水平移動、再於目標上方垂直下降。路徑以半格為步長並繞過其他已部署無人機的位置；每台機依索引使用相隔 0.62 世界單位的巡航高度層。升降及水平移動以固定 1.0 世界單位／秒計算，水平航段時間依路徑長度計算。多機不再透過碰撞時暫停或側移來協調。



無人機機身以 +Z 為正面，依每影格水平位移轉向；停留及純升降時保持最近一次朝向。

停靠平台拖曳預覽會在土地表面高度繪出綠色方框投影，拖曳結束或取消時隨預覽清除。植物濕潤期限由 `plot.waterUntil` 表示；期限內每影格繪製水氣粒子，並降低該植物中央土壤床顏色，草綠浮島外框維持原色；期限後土壤床恢復。點擊場景中未命中土地或停靠平台的區域時，清除全部選取狀態。自動模式按鈕與無人機狀態文字保留 8px 水平間隔。

農地資訊提供刪除操作並以瀏覽器確認對話框二次確認；含作物地塊會提示作物一併移除。無人機工作佇列未清空時禁止刪除，避免工作索引因地塊陣列位移而指向其他地塊。最後一塊土地不可刪除；地塊可自由分散配置，刪除不檢查其餘地塊是否連通。刪除後存檔及 3D 土地列表同步更新。

`game.drones` 保存每台無人機的專屬停靠座標、部署狀態和部署序號；`game.deploymentSequence` 為後續部署產生遞增序號；`game.droneCount` 維持相容舊存檔，上限 8 台，每台購價 150 金幣。舊版存檔會保留原主停靠坪台並為其他無人機配置空位。場景中每台無人機各停靠於自己的坪台；土地移動會避開全部坪台。`activeJobs` 以無人機索引保存執行中的工作，多台已部署無人機可以同時執行自動或手動任務；同一地塊同時只派一項工作，擴建工作單獨執行。場景為每台無人機保存獨立動畫、位置和朝向；每台機依索引使用分層巡航高度，出勤及返航路徑以 A* 格點規劃並繞過其他已部署無人機位置。路徑動畫沿累積路徑距離推進；未找到路徑時使用直接航段作為回退，確保不會因尋路失敗停住。未購買或已收起的陣列槽位不參與規劃。

機隊清單逐台顯示坪台位置及部署狀態。收起的無人機及其坪台都從場景隱藏，但保留坪台座標且不會接取新工作；工作中的無人機不能收起。部署會顯示該機並讓派工器恢復分派；若佇列有等待工作，立即重新啟動派工。

每台 `game.drones[]` 保存 0–100 電量及最近更新時間；舊存檔缺少電量時以滿電載入。無人機執行出勤、工作及返航動畫時按時間差以每秒 0.32 個百分點耗電；晴朗完整白天時，即使出勤也同時以每秒 0.44 個百分點補電，因此工作淨回充為每秒 0.12 個百分點。閒置時以每秒 0.44 個百分點充電；陰雨、清晨、黃昏及夜間不充電。離線期間不變更電量，返回時重設電量更新時間；每架無人機每 10 秒保存。派工會依停靠點至目標的距離預留全額工作耗電，最低預留 8%，不把途中日照收益列入安全額度；不足時工作留在佇列，充電至足夠後再派出。已開始的動畫即使意外耗盡電量仍完成既有工作，不中斷結算；頁面隱藏時動畫暫停，因此電量亦暫停變化。機隊列表顯示電量百分比，場景中央八面體依同一電量由綠平順轉紅。

自動模式的地塊收成結算後立即重新規劃佇列；若指定花種和剩餘金幣允許，該地塊的補種工作會優先排在既有等待工作之前。

離線時間保存於 `game.lastOnlineAt`，玩家下次載入時記錄 `game.lastOfflineReturnAt`。離線結算最多推進 24 小時已種花卉的成熟倒數；成熟作物留在地塊，不進行收成、補種或其他遊戲狀態結算。返回時凍結離線期間的虛擬日夜與天氣，並重設無人機電量計時錨點。上線後顯示離線時長及成熟倒數更新提示；舊存檔缺少時間戳時從下次離開起記錄。

每株作物的澆水生長加速持續 30 秒，生長速率為基礎值的 1.2 倍；`plot.waterStartedAt` 與 `plot.waterUntil` 用於計算即時加速及到期結算，兩者隨存檔保留。陰雨狀態切換時立即重建場景土地，雨中使用濕土色；雨滴特效限於下雨時，作物根部水滴／水氣動畫由獨立的 `waterUntil` 控制，因此可安排在雨停後播放。雨停會把所有已種下作物記為已澆水並啟動新一段 30 秒濕潤加速；若覆寫先前期限，先將舊期限已累積的加速結算入 `growthBonusMs`。存檔中的 `lastObservedRaining` 用來在即時及重新載入跨越雨停時各結算一次。



重置進度按鈕位於場景右上方；HUD 收合時會與相機切換、圖鑑、擴建及手機縮放控制一同隱藏，展開後恢復。確認對話框說明將清除的遊戲資料；確認後只移除 sky-garden-save-v1 這個遊戲存檔並重新載入。isResetting 會阻止頁面離開事件或動畫回呼將舊進度重新寫回；取消不修改遊戲狀態。


繡球花（花種索引 7）使用 24 朵沿球面均勻分布的小花組成球狀花序；每朵小花由四片低多邊形萼片與中央花心構成。萼片顏色沿用花種或玩家設定的自訂花色，並以有限色階差異呈現層次。


向日葵成熟花頭由兩層弧拱放射舌狀花、具厚度的花盤、螺旋排列的深色盤花小花與花盤苞片構成；舌狀花沿用玩家設定花色，盤花保持深褐色以呈現中心對比。

風信子成熟模型以多層六裂小花構成直立、頂端略收窄的圓柱狀總狀花序，小花色沿用花種或玩家設定色。

鈴蘭成熟植株以加長寬葉襯托弧垂總狀花序；花序包含六朵六裂鐘形花，保留花口外翻和花色自訂。

玫瑰花頭由四道半徑遞減、角度逐層錯位的花瓣環構成；各瓣由花托向上拱起並向外同向偏轉，形成圓鼓側面、上翻外瓣及緊密旋卷花心。基部附五片外展綠色萼片，各瓣沿用選定的玫瑰花色。

鬱金香花頭以六片相疊花被片圍成淺杯形，花被片沿用變種色並加入交錯明暗；花心帶金黃色細節。

康乃馨花頭使用三層拱起交錯的鋸齒扇形花瓣，呈現立體層疊、褶皺與流蘇邊，保留自訂花色。

菊花成熟花頭以兩圈中段隆起的細長放射舌狀花形成圓頂，環繞螺旋排列的金色盤花小花；中心盤花與花瓣色分開處理，花瓣仍支援自訂色。

薰衣草花穗以七層交錯輪生的小花構成；小花加入雙唇花冠色塊及綠色苞片，並由下向上漸窄。

牡丹花頭使用三層交錯重瓣，由寬大外層守護瓣逐步過渡至中央花瓣簇，基部附五枚綠色萼片與金色花心；各花瓣沿用種子或變種色。

鈴蘭花序的小花沿弧形梗交錯分布；每朵在前後深度與高度略有差異，避免呈現等距直線排列。玫瑰花頭共用成熟花冠高度 bloomY，該值須在玫瑰專屬幾何分支前初始化。

自動播種花種由花卉圖鑑各花種資訊卡設定，偏好獨立儲存於 `sky-garden-auto-crops-v1`，與花園存檔的 `autoCropSelection` 保持同步；花園頁透過 `storage` 事件接收其他分頁的變更。關閉自動模式會立即清空工作佇列中的所有等待工作，已啟動的工作仍按既有動畫流程完成。

地塊與無人機坪台共用長按進入移動、短按循環切換移動／高度模式的操作方式。場景在移動模式顯示黃色平面四向箭頭，在高度模式顯示青綠色上下箭頭；箭頭跟隨所選地塊或坪台。

2D 俯視相機以可變高度控制滾輪縮放，WASD 平移相機中心。選取地塊進入移動模式後，WASD 改為逐格移動該地塊；高度模式下 W/S 以 0.5 土地單位調整地塊高度，這些編輯輸入不會同時移動相機。

手機直式介面以視窗高度呈現空島場景，底部提供可觸控的放大／縮小按鈕與水平捲動的農地捷徑；觸控螢幕可用雙指捏合縮放相機，桌面版仍保留滾輪縮放。手機直式版面不改變遊戲存檔格式或玩法狀態。

## 手機介面與無人機面板

花園在手機直式版隱藏場景操作提示及底部農地快捷列，桌面版保留；無人機工作佇列與機隊管理預設收合，透過花園資訊欄按鈕開啟，面板互動會重設五秒閒置收合倒數。花卉圖鑑在窄螢幕以正方形模型視窗呈現，變種編輯區與模型視窗採相同寬度規則。這些調整僅涉及介面與互動，不改變遊戲存檔格式。


擴建價格以目前農地數量計算：初始三塊之外的第一塊為 75 金幣，之後每塊價格乘以 2；計算及實際扣款共用同一價格函式。無人機購買價格以 150 金幣作為第一台基準，開局第一台免費，購買第二台時價格為 1200 金幣，之後每台乘以 8，最多八台。
